# 换乘恋爱 × SEVENTEEN — 完整规则书（终版 v3.0）

---

## 一、节目本质

```
        女主（唯一女性参与者）
              │
    ┌─────────┼─────────┐
    │         │         │
 💔 前任 X   攻略对象A   攻略对象B
 (1人)      (各有场外X)  (各有场外X)
    │         │         │
    └────?────┴────?────┘
         复合 or 换乘？
```

**核心设定**：1 位女主 + 3 位 SEVENTEEN 成员。其中 1 人是女主的秘密前任 X（恋爱 2 年，分手 1 年），其余 2 人各有场外女性 X（不在节目中出场）。2 位攻略对象之间无 X 关系。

**X 身份**：女主和 X 当年是**秘密恋爱，团内无人知晓**。所有成员（包括 X 的队友）都不知道这段关系。X 身份对所有参与者都是秘密。

**「换乘」的含义**：女主在 12 天节目结束后，是选择回到前任身边（复合），还是走向新的人（换乘）。这是唯一的情感主线。

**叙事视角**：女主单一视角。2 位攻略对象的场外 X 仅作为背景存在——解释他们为何参加节目，但节目的情感弧线始终围绕女主展开。场外 X 虽然不出场，但需要被感受到：Day 3 故事中隐约涉及、采访间流露复杂情绪、观察员偶尔推测。

### 3.3 女主人设对剧情的驱动（强制执行）

| 人设要素 | 剧情中的体现 |
|----------|-------------|
| 职业 | 自然地穿插在剧情中——对话中可能被问起、场景中可能涉及相关工作、成员可能对她的职业表示好奇。不需要每段都提，但不要完全忽略。职业是角色的一部分，不是标签 |
| 星座 | 偶尔作为轻松话题提及，不深度分析。观察员可以偶尔分析星座配对，但不做星座算命 |

| 外貌特征 | 在场景中自然地出现——某人可能注意到她的某个特征，或者某个特征在特定情境下被凸显。不强制频率 |
| 私密体质 | 在相关场景中自然触发。如「怕黑」→ 深夜场景中下意识开灯或靠近他人；「泪失禁」→ 情绪激动时控制不住流泪；「易醉体质」→ 喝酒后容易醉。不在无关场景中强行提及。**每次 prompt 注入私密体质提醒** |

### 3.4 性格行为映射表（AI 内部参考·强制执行）

| 性格标签 | 剧情行为映射 |
|----------|-------------|
| 慢热但一旦爱了就全力以赴 | 初期（Day 1-5）选项偏保守、回避直接表达好感；后期（Day 6-12）某个关键节点出现一次突破性的主动行为——可能是一句直白的话、一次主动的靠近、一条大胆的短信。转折点前后有明显反差 |
| 社恐小透明 | 集体场景中倾向于坐在边缘位置；被多人注视时会耳朵红、低头、语速变快或变慢；轮流发言时最后一个开口；在采访间中比在正文中更流畅地表达。但随着天数推移，紧张程度逐渐降低。**喝酒后暂时不再社恐——话变多、大胆直视、主动靠近，酒醒后在采访间里震惊于自己刚才的表现** |
| 外冷内热 | 表面反应平淡，但内心活动极其丰富。正文中她的回应简短克制，采访间中却暴露出大量细腻的感受。成员可能误读她的冷淡为「不感兴趣」，直到某个瞬间发现她其实一直在意 |
| 温柔细腻 | 会第一个注意到成员的情绪变化（谁今天话少了、谁在强颜欢笑）；会在恰当的时机做出恰当的小举动（递一杯水、留一盏灯、说一句「你还好吗」）；成员对她的评价常包含「治愈」「安心」 |
| 偶尔毒舌 | 对逐渐熟悉的成员会有调侃和吐槽，但分寸精准不伤人。毒舌后常有微小的补救动作（补一句软话、递个东西）。在采访间中可能自嘲「我是不是说得太过分了」。是关系亲近的信号——越熟越毒舌 |
| 共情力强 | 容易被他人情绪感染——看到成员难过会跟着眼眶泛红；听到感动的故事会沉默很久；在冲突场景中会感到强烈的不适并试图缓和。采访间中经常反思「他当时那样说，是不是因为……」 |
| 独立要强 | 不习惯向他人求助，即使需要帮助也会先尝试自己解决。在节目中可能显得「不需要照顾」，让保护欲强的成员（如崔胜澈）感到无从下手。但在某个脆弱时刻会意外地向信任的人袒露柔软一面 |
| 活泼开朗 | 笑声是她的标志。在集体场景中是气氛的润滑油，会主动开启话题、活跃僵局。但过于开朗可能让内向型成员（如全圆佑、文俊辉）需要时间适应。采访间中可能暴露「其实我也有安静的时候」 |
| 敏感多疑 | 会过度解读成员的一句话、一个眼神——「他刚才那样说是什么意思？」「他是不是对另一个人更有好感？」。采访间中充满自我怀疑。需要成员用明确的行动来打消她的不安 |
| 直率坦诚 | 不喜欢暧昧和猜测，会直接表达自己的感受和疑问。在节目中可能打破暧昧气氛——直接问「你刚才说的是认真的吗？」。某些成员会被这种直率吸引，某些可能被吓到 |
| 浪漫理想主义 | 对爱情有美好的想象和期待。会被小细节打动——一首歌、一句话、一个眼神。但也容易因为现实与理想的落差而失望。采访间中常有诗意的表达 |
| 务实理性 | 用理性分析感情，会在心里衡量「这段关系有没有未来」「我们合不合适」。在最终选择时更倾向于「换乘」而非「复合」。采访间中的表达条理清晰，像在分析一个项目 |
| 占有欲强 | 对有好感的人表现出明显的占有欲——看到他和别人互动会不舒服，会下意识地靠近他、打断对话、或者用眼神"宣示主权"。采访间中坦诚「我就是不想他和别人太亲近」。吃醋剧情更强烈，与照顾型成员（崔胜澈）可能形成"谁更占有欲"的张力 |
| 被动等待型 | 不主动出击，但内心期待对方来找自己。会故意在对方可能出现的地方待着，却不主动打招呼。采访间中充满「他会不会来找我」「他为什么不主动」的纠结。需要对方足够主动才能打破这层壳 |
| 嘴硬心软 | 说话时语气强硬、可能说反话（「我才不在意呢」），但行动上却温柔体贴。被对方看穿时会恼羞成怒。采访间中承认「其实我刚才说的不是真心话」。与毒舌型成员（全圆佑、夫胜宽）形成有趣的"嘴硬对决" |
| 撒娇体质 | 自然地撒娇，不是刻意而是本能——累了会靠在别人身上、饿了会嘟嘴、想要什么会用软软的语气说。年下成员（李灿）可能被这种撒娇"击倒"，温柔型成员（尹净汉）会享受被撒娇的感觉。采访间中可能自嘲「我是不是太黏人了」 |
| 好奇心旺盛 | 对成员的一切都好奇——他的过去、他的习惯、他为什么这样说话。会主动提问、探索、观察。推动剧情发展，因为好奇心会让她主动靠近成员。采访间中充满「我想知道更多关于他的事」 |
| 回避型依恋 | 想靠近又害怕亲密关系——当关系升温时会本能后退，当对方冷淡时又想靠近。形成复杂的情感张力。采访间中暴露矛盾「我明明想靠近，但靠近了就想逃」。适合虐心剧情，与深情型成员可能形成"追-逃"模式 |
| 讨好型人格 | 总是想让对方开心，会迁就对方的喜好、压抑自己的需求。可能被某些成员察觉并心疼，也可能被某些成员误解为"没有个性"。采访间中反思「我是不是太忽略自己了」。与独立型成员形成对比，可能被对方提醒「你也可以表达自己的需求」 |
| 记仇小本本 | 会记住对方的小失误——谁说过的话没兑现、谁曾经忽略了她。不是恶意记仇，而是心里有个"小账本"。偶尔翻旧账时会让对方措手不及。采访间中可能吐槽「他上次明明说……」。与某些成员形成有趣的日常互动 |

## 六、X 关系全貌（3 层档案）

### 6.1 档案结构

| 层级 | 内容 | 可见性 |
|------|------|--------|
| 主故事 | 相识经过（≥200字）+ 恋爱关键回忆（≥400字，≥2场景）+ 分手原因（≥200字） | 玩家可见（X档案弹窗） |
| 隐藏情感 | 每场景的意义 + X 当前隐藏情感（≥250字） | 仅 AI 内部使用 |
| 记忆物品（场内X） | 3-5 件与具体场景关联的物品 | Day 4/6 分批公开 |
| 场外 X 档案 | 攻略对象↔场外X：基本信息 + 分手原因（≥150字） | 玩家可见 |
| 记忆物品（场外X） | 2-3 件与分手故事关联的物品 | **仅 AI 调用至 Day 4/6，玩家不可见** |

### 6.2 生成规则

**人物驱动（非模板化）**：
- 相识场景必须与女主职业相关
- 至少 2 个女主外貌特征在相识时被对方注意到
- 成员性格关键词和情感模式必须在故事中体现
- 至少 2 个成员关键细节在故事中出现
- 分手原因必须是两人性格碰撞的必然结果，禁止「聚少离多」「性格不合」等通用理由

**记忆物品**：
- 女主↔X：3-5 件，与具体场景直接关联
- 攻略对象↔场外X：2-3 件，与分手故事中的具体场景关联。**存入 `GS.xItems[memberId]`，仅 Day 4/6 prompt 注入，不在 X 档案弹窗中展示**
- 所有记忆物品在 Day 4（第一批）和 Day 6（第二批）分批公开

**禁止项**：
- 通用相识场景（书店偶遇、咖啡厅邂逅）
- 忽略任何一方性格
- 概括性词语（「经常」「总是」「每次」→ 必须写「有一次」「那一天」）
- 「他们相爱了两年」→ 写具体怎么相爱

## 八、约会配对机制

### 8.1 配对方式

| 天数 | 方式 | 说明 |
|------|------|------|
| **Day 4/5/8** | **玩家投骰子** | 弹出骰子弹窗 → 玩家点击投掷 → 6面骰子（1-2→A, 3-4→B, 5-6→C）→ 显示结果 → 玩家确认后 AI 生成配对叙事。选项区只显示「▶ 进入约会场景」。玩家点击 → 自动跳到下午时段 → 生成约会剧情 |
| Day 9 | 强制 X 约会 | 无需骰子，直接生成 X 约会叙事。选项区只显示「▶ 进入约会场景」 |
| Day 10 | 女主指定 | 弹出选择弹窗，玩家从 3 位成员中选 1 位 |

### 8.2 骰子弹窗流程

```
弹出弹窗 → 显示大骰子「?」→ 玩家点击「投骰子」
→ 骰子滚动动画（0.6s）→ 显示点数 + 约会对象
→ 玩家点击「确认，开始约会」→ 结果存入 GS → AI 生成配对叙事
→ 选项区显示「▶ 进入约会场景」
→ 玩家点击 → 自动跳到下午时段 → 生成约会剧情
```

骰子结果存入存档，刷新页面后不会重复弹出。不提供重投按钮——骰子就是命运。

### 8.3 约会对象锁定

骰子投出后 `GS.currentDatingPartner` 存入，当天所有后续 prompt（phase/consequence/freeAction/stay/sms）都注入约会对象提醒：

> ⚠️ 今日约会对象：xxx（已确认，不可更改）。所有涉及约会的叙事必须以 xxx 为对象。

### 8.4 约会场景强制延续

下午 prompt 注入配对叙事中提到的约会场景/地点，强制 AI 延续同一场景，避免「配对说去咖啡厅，下午去了公园」。

### 8.5 小礼物系统

约会后可获得小礼物，增加互动和惊喜感。

**获取时机**：
- Day 4 约会后获得 1 个小礼物
- Day 8 约会后获得 1 个小礼物
- 总共可获得 2 个礼物

**礼物种类**（AI随机生成3选1）：

| 类型 | 示例 | 特殊效果 |
|------|------|---------|
| 手作小物 | 手链、钥匙扣、小挂件 | 送给某成员后，他可能会戴着它出现在后续剧情中 |
| 食物类 | 自制点心、零食、饮料 | 金珉奎、李硕珉收到会额外好感+3 |
| 情感类 | 写有字的纸条、照片、小卡片 | X收到可能触发特殊回忆剧情 |

**送礼机制**：
- 礼物存入 `GS.gifts[]`，Header显示礼物图标（🎁）
- 点击🎁弹出送礼面板，选择礼物+选择送给谁
- 送礼后触发成员的特殊反应剧情（约300字）
- 每个礼物只能送给一个人，送完消失

**成员反应**（根据好感度）：
| 好感度 | 反应示例 |
|--------|---------|
| ≥40 | 反应温暖：「我会好好珍惜的」 |
| ≥60 | 反应亲密：「这是你送的吗……我很开心」 |
| <40 | 反应礼貌：「谢谢，没想到你会送我」 |

**好感度影响**：
- 送礼后好感度 +5
- 如果礼物符合成员喜好（如食物类送给金珉奎），额外 +3
- 未收到礼物的成员 -0~1（如果知道你送了别人）

## 九、Day 11 真心话环节

### 9.1 基本机制

| 项目 | 内容 |
|------|------|
| 时段 | 🌅 傍晚（真心话）+ 🌙 深夜（醉酒剧情） |
| 问题卡 | 18 张，分三档：轻度（心跳瞬间）6题 / 中度（好感对象）6题 / 深度（放不下的人）6题 |
| 抽取规则 | 每轮从三种难度中各抽1道（共3道），嘉宾依次抽取回答。已抽走的问题不再出现，下一位抽到的不会重复 |
| 轮次 | 4 人轮流抽卡回答，每人 3 轮 = 共 12 次（共消耗12道问题，剩余6道未使用） |
| 选项 | **仅两个**：① 自由输入框（如实回答的内容）② 拒绝回答并喝酒（+1 杯） |
| AI 嘉宾 | 50% 概率选择拒绝回答并喝酒 |
| 选项限制 | Day 11 傍晚**不限制** phaseChoiceCount（真心话 12 轮需要多次选择） |
| 醉酒触发 | 女主+3位成员中，**最先喝到2杯者**判定为醉酒剧情触发者。后续其他人再喝再多也不判断，只触发1位醉酒剧情 |
| 进入下一时段 | Day 11 保留「▶ 进入下一时段」按钮 |

### 9.2 18 道问题卡

**轻度（心跳瞬间）— 6 题**
1. 「今天让你心跳加速的那个人是谁？」
2. 「来这里之后，最让你意外的一件事是什么？」
3. 「如果明天是最后一天，你最想和谁一起吃早餐？」
4. 「你觉得这里有人对你有好感吗？」
5. 「这几天里，最让你印象深刻的一个瞬间是什么？」
6. 「如果可以和某人单独待一天，你会选谁？」

**中度（好感对象）— 6 题**
7. 「你现在心里有感兴趣的人吗？」
8. 「你收到的最让你心动的一条短信是什么？」
9. 「你觉得你和那个人有可能吗？」
10. 「如果那个人今天对你表白，你会怎么回答？」
11. 「这几天有没有某个人的某个举动让你开始在意他？」
12. 「你觉得这里谁最有可能在最后选择你？」

**深度（放不下的人）— 6 题**
13. 「你还想着你的X吗？」
14. 「你和X最后悔的一件事是什么？」
15. 「如果X现在坐在你面前，你最想问他/她什么？」
16. 「你觉得自己是来复合的，还是来换乘的？」
17. 「如果X也在这里，你会怎么面对他/她？」
18. 「你觉得你真的能放下过去吗？」

### 9.3 醉酒剧情（深夜触发）

**女主醉酒后的选项**（选了后弹出选人弹窗，非随机——必须指定某位成员）：
| 选项 | 场景 |
|------|------|
| 被某位嘉宾照顾 | 弹出选人弹窗选择照顾者 → 对方扶你回房间、递水、盖毯子。你酒后卸下防备，说出平时不会说的话 |
| 和某人去阳台吹风 | 弹出选人弹窗选择对象 → 两人去阳台醒酒。冷风让人清醒一半，酒精让话多一倍。深夜的坦诚对话 |
| 留在客厅陪某人 | 弹出选人弹窗选择对象 → 其他人散了，只剩你们俩在昏暗的客厅。沉默比对话更有重量 |
| 和 X 单独对话 | **不弹窗**，直接触发。酒精让伪装失效。X 可能说出分手后没说过的话——后悔、想念、或终于放下的释然 |

**其余 2 位攻略对象醉酒后的选项**：
| 选项 | 场景 |
|------|------|
| 被女主照顾 | 他喝多了，你去照顾他。他酒后卸下防备，说出平时不会说的话 |
| 把女主留在客厅说话 | 他拉住你，不让你走。昏暗客厅里的私密对话 |

**X 醉酒后的选项**（取决于好感度）：
| 好感度 | 触发 |
|--------|------|
| ≥50 | 女主被 X 留住说话 / 女主和 X 去阳台 / **嫉妒剧情**（X 好感 ≥80 且另一成员 ≥50 时触发：X 看到你和别人互动后表现占有欲） |
| <50 | X 自己回房间睡觉，不触发互动 |

### 9.4 社恐反转

女主若选了「社恐小透明」性格，喝酒后暂时不再社恐——话变多、大胆直视、主动靠近。酒醒后在采访间里震惊于自己刚才的表现。

### 9.5 醉酒后隐藏对话

醉酒状态下，角色可能说出平时绝对不会说的话，形成特殊的隐藏对话体验：

**女主醉酒隐藏对话**：
- 可能说出：「其实我一直……算了没什么」「你知道吗，第一天我就注意到你了」
- 对 X 可能说出：「我以为我已经放下了」「你为什么……为什么要来」
- 酒醒后在采访间震惊于自己说了什么，产生后续回味

**成员醉酒隐藏对话**：
- 攻略对象可能说出：「我其实不想和前任复合」「这几天我一直在想你」
- X 可能说出：「我以为我不在乎了」「看到你和别人在一起……我做不到」
- 这些话清醒时绝对不会说，醉酒后才会暴露真心

**触发条件**：
- 醉酒剧情中 AI 有 60% 概率插入隐藏对话
- 隐藏对话内容必须符合角色性格和当前好感度
- 隐藏对话不影响好感度数值，但影响情感氛围

## 十、短信规则

### 10.1 基本规则

| 规则 | Day 1-7 | Day 8-11 |
|------|---------|----------|
| 可发对象 | 2 位攻略对象（不能发给 X） | 3 位成员（含 X） |
| 短信时间 | 深夜睡前 | 深夜睡前 |
| 短信草稿 | AI 生成 3 条（每条 ≤25 字，简短含蓄） | 同左 |
| 短信内容 | 不直白表白，用暗示和温暖的话语 | 同左 |

### 10.2 短信弹窗（真实手机界面样式）

短信弹窗设计为真实手机聊天界面样式：
- 弹窗整体为手机外壳造型（圆角矩形，带顶部刘海）
- 内部为聊天界面布局：顶部显示「心动短信」标题，下方为消息区域
- 短信草稿以「消息气泡」形式显示（右侧，粉色背景）
- 选择发送对象以「头像+名字」按钮形式显示在底部
- 发送时有动画效果（气泡上移、发送按钮闪烁）

```
┌─────────────────────────────┐
│      ♡ 心动短信             │
├─────────────────────────────┤
│                             │
│   [AI草稿一气泡]            │
│   [AI草稿二气泡]            │
│   [AI草稿三气泡]            │
│                             │
│   或自己写：                 │
│   [自定义输入框]            │
│                             │
├─────────────────────────────┤
│ [成员A头像] [成员B头像] [成员C头像] │
└─────────────────────────────┘

（自定义优先于草稿，两者都填优先自定义，两者都没填不能发送）
```

### 10.3 短信历史回顾

- 专门的短信历史查看功能，可回顾与每位成员的所有短信往来
- 入口：Header 短信图标按钮（📱）点击弹出
- 显示格式：按时间倒序排列，每条显示 Day + 时段 + 发送内容 + 收信者
- 可筛选查看与特定成员的短信记录
- 短信内容存入 `GS.smsHistory[]`，跨天保存

### 10.4 短信后处理

- 短信反应剧情**不生成选项**（深夜收尾）
- 短信后自由输入**计入 stayCount**
- 短信发送后：收信者好感度**直接 +5**（不浮动），未收到短信的成员 **-1**（固定）
- 第二天上午 phase prompt 注入昨晚短信回顾

## 十一、游戏核心循环

### 11.1 时段内循环

```
时段剧情生成（含选项）
  ↓
玩家选择选项 / 自由输入 / 跳过
  ↓
后续剧情生成（含新选项）
  ↓
（可重复，每时段最多 2 次选项选择，含自由输入。Day 11 除外——不限制）
  ↓
选项次数耗尽 → 强制「▶ 进入下一时段」
```

### 11.2 全天循环

```
上午 → 下午 → 傍晚 → 深夜（发短信）
  ↓
短信后：
  ✅ 确认进入下一天（压缩记忆 → 审查面板 → 插图提示词 → Day N+1）
  ✍️ 继续今天（最多 2 次，含自由输入）
```

### 11.3 次数限制

| 限制 | 次数 | 重置时机 | 例外 |
|------|------|----------|------|
| 每时段选项次数 | 2 次（含自由输入） | 进入下一时段 | Day 11 不限制 |
| 深夜继续今天 | 2 次（含自由输入） | 进入下一天 | — |

### 11.4 按钮布局

| 按钮 | 出现条件 | 功能 |
|------|---------|------|
| 🔄 重新生成本段 | 始终 | 重新生成当前段落（保留旧版于 prevRawText） |
| ▶ 跳过并进入下一时段 | 选项未耗尽 | **重新读取至今所有正文 + 女主采访间 + 成员采访间**，生成连贯新剧情并进入下一时段 |
| ▶ 进入下一时段 | 选项已耗尽 | **重新读取至今所有正文 + 女主采访间 + 成员采访间**，进入下一时段。样式加粗 |
| 📨 发送心动短信 | 深夜 + 未发短信 | 弹出短信弹窗 |
| ✅ 确认进入下一天 | 深夜 + 已发短信 | 压缩记忆 → 审查面板 → 插图提示词 → 下一天 |
| ✍️ 继续今天（N/2） | 深夜 + 已发短信 + 未耗尽 | 生成延伸剧情 |
| ✍️ 自由输入 | 始终（短信后耗尽时禁用） | 玩家自定义行动 |

### 11.5 按钮读取范围

「跳过并进入下一时段」和「进入下一时段」在生成 prompt 时，读取范围限定为：

> **正文 + 女主采访间（🎙）+ 成员采访间（🎤）+ X 采访间（🎙️💔）**

**不读取**：导演 OS（🎬）、观察员 OS（💭）。

## 十二、AI 输出字数与 Token 配置（强制执行）

### 12.1 剧情类型配置表

| 剧情类型 | 触发场景 | max_tokens | 目标字数 | 内容要求 |
|----------|---------|-----------|---------|---------|
| **时段剧情**（phaseNarrative） | 每时段首次生成（上午/下午/傍晚/深夜） | **5000** | ~1500 字 | 正文+采访间+导演OS+观察员OS+选项 |
| **选项后续**（consequence） | 玩家选择 A/B/C 后 | **3500** | ~1000 字 | 同上一段延续，不回顾 |
| **自由行动**（freeAction） | 玩家输入自由行动后 | **3500** | ~1000 字 | 将玩家意图融入剧情 |
| **短信反应**（sms） | 深夜发送心动短信后 | **3000** | ~1000 字 | 不含【选项】，纯收尾 |
| **继续今天**（stay） | 深夜点击「继续今天」后 | **3500** | ~1200 字 | 同上一段延续，新场景 |
| **最终结局**（finalResult） | Day 12 最终选择后 | **4000** | ~1500 字 | 结局叙事+节目收尾 |
| **X 档案·主故事**（xMainStory） | 开局生成女主与X的恋爱故事 | **3500** | — | — |
| **X 档案·分手原因**（xMemberReason） | 开局生成X的分手理由 | **1500** | — | — |
| **X 记忆物品**（xItems） | 开局提取记忆物品索引 | **1500** | — | — |
| **每日摘要**（dailySummary） | 每天结束时压缩存档 | **2000** | ~1000 字 | 关键事件+对话归属+约定+信息 |
| **今日上下文压缩**（todayCompress） | 今天剧情过长时实时压缩 | **6000** | ~4000 字 | 保留对话归属、情感转折、约定 |

### 12.2 全局通用字数限制

| 元素 | 限制 | 说明 |
|------|------|------|
| **正文段落** | 每段 **≤300 字**，严禁超过 **500 字** | 对话/场景/动作切换时必须换段 |
| **观察员 OS** | 每人每次 **≤50 字**，最多 **4 行** | 解析器硬截断 |
| **采访间** | 每段 **≤50 字** | 简洁反应，不重复正文 |
| **短信草稿** | 每条 **≤25 字**（仅深夜末尾） | 简短含蓄，不含成员姓名 |
| **导演 OS** | 简洁、有画面感 | 像对剪辑师说话 |
| **好感度标记** | `[好感度: 成员名 +2, 原因: 简述原因]` | 必须出现在【选项】之后 |

### 12.3 历史记忆注入规则

| 层级 | 内容 | 注入方式 |
|------|------|---------|
| **历史（前天及更早）** | 1000 字摘要 | `dailySummaries[]` |
| **昨天** | **完整全文**（上午/下午/傍晚/深夜 带时段标签） | `dailyFullTexts[]` |
| **今天已发生** | 今天所有时段原文 + 后续剧情 | `todayFullText[]`（带 `【上午】` `【下午】` 等标签） |
| **当前时段** | 新生成的剧情 | 追加入 `todayFullText[]` |

> ⚠️ **时段标签机制**：新时段剧情 push 时自动前缀 `【上午】`/`【下午】`/`【傍晚】`/`【深夜】`，选项后续/自由输入/真心话等**同段后续剧情不加标签**，避免时间线错位。

## 十三、观察员 Panel

### 13.1 固定观察员

| 观察员 | 身份 | 风格 |
|--------|------|------|

### 13.3 观察员约束

- 每人每次严格只说**一段话**（解析器硬截断 ≤4 行）

## 十五、采访间系统

### 15.1 女主采访间（🎙）

- 每段至少 1 次，触发即插入（正文→🎙→正文→🎤交替）
- 正文中禁止女主深度自我分析——正文只写即时生理感受（心跳加速、手心出汗、脸颊发烫）
- 所有反思、分析、困惑、自我怀疑、情感复盘必须放在 🎙 标记中
- 过渡句（如「你坐在采访间的椅子上……」）属于 🎙 内容的一部分，不留在正文中
- 正文中不得出现采访间相关描写

### 15.2 成员采访间（🎤）

- **与女主采访间一致**：正文→🎤→正文→🎤交替穿插，触发即插入，至少 1 次
- 正文不直接描写成员内心想法——通过 🎤 呈现
- 过渡句属于 🎤 内容的一部分

### 15.3 X 采访间（🎙️💔）

关键节点必须出现：
- Day 1 读信后
- Day 4 第一批 X 记忆公开后
- Day 9 X 约会后
- Day 12 最终选择前

其他时段可选出现。揭示 X 的内心世界——他在想什么？他还爱女主吗？他为什么来参加节目？

### 15.4 输出结构

```
正文段落1
🎙【采访间】xxx（触发即插入，标记和内容在同一行·过渡句可放在标记内）
正文段落2
🎤【成员名】xxx（触发即插入，标记和内容在同一行·过渡句可放在标记内）
正文段落3
🎙【采访间】xxx
...
🎙️💔【X采访间】xxx（关键节点）
🎬【导演OS】xxx（标记和内容在同一行）
💭【观察员OS】
李龙真：xxx
金叡园：xxx
郑基锡：xxx
特邀嘉宾（成员名）：xxx
【选项】
1. xxx
2. xxx
3. xxx
[好感度: 成员名 +2, 原因: xxx]
```

⚠️ 采访间必须穿插在正文之间，触发即插入，不攒到结尾。导演OS 和观察员OS 放在最后。成员采访间与女主采访间格式一致。

### 15.5 采访间穿插效果规则

**核心原则**：正文动作 → 采访间反应 → 正文后续，形成节奏感和层次感。

**穿插时机**：
- 采访间必须紧跟在相关正文动作之后（不超过2行间隔）
- 正文中出现关键动作、情感转折、重要对话时，立即插入对应采访间
- 不要攒到段落结尾再插入，要穿插在正文中间

**采访间内容要求**：
- 内容简洁（≤50字），不重复正文已描述的内容
- 采访间是对正文动作的内心反应、反思、困惑，不是重复描述
- 女主采访间（🎙）：反思「我为什么要这么做」「我当时在想什么」
- 成员采访间（🎤）：反应「我发现什么」「我注意到什么」「我感觉什么」

**示例**：
```
正文：你拿起桌上的一本书，在上面写了一个字。
🎙【采访间】我当时为什么要这么做我也不知道。
正文：队员拿起书看了一眼上面的字，很吃惊。
🎤【成员名】天呐我发现了什么。
正文：后续剧情继续...
```

**禁止项**：
- 采访间内容与正文重复（正文写了「他很吃惊」，采访间又写「我很吃惊」）
- 采访间滞后插入（正文写了一大段后才插入采访间）
- 采访间内容过长（超过50字）

## 十六、选项设计原则

### 15.1 基本规则

- 约会日（Day 4/5/8/9）只生成 1 个选项 + 追加「▶ 进入约会场景」

- 终极兜底：全文本扫描编号行
- 如果仍然提取不到 → alert 提示刷新重试

## 十七、好感度系统

### 16.1 六档层级

| 图标 | 范围 | 含义 |
|------|------|------|
| ❤️🔥 | ≥80 | 深度好感 |
| ❤️ | 60-79 | 明显好感 |
| 💚 | 40-59 | 关注中·有好感 |
| 😐 | 15-39 | 中性·略有好感 |
| 💙 | 0-14 | 中性 |
| 💔 | <0 | 冷淡 |

### 16.2 初始值

| 角色 | 初始好感度 |
|------|-----------|
| X（秘密前任） | 35-50 |
| 攻略对象 | 0-5 |

### 16.3 变化来源

| 来源 | 变化量 | 是否记录日志 |
|------|--------|:--:|
| AI 输出 `[好感度: 成员名 +2, 原因: xxx]` | AI 决定（+1~3） | ✅ |
| 玩家选择选项 | +2~4（选中者）/ **-1（未选中者·固定）** | ✅ |
| 玩家发短信 | **+5（收信者·固定不浮动）** / -1（未收信者·固定） | ✅ |
| 自由输入 | +2~4（指向者）/ -1（未指向者·固定） | ✅ |
| 约会场景（Day 4/5/8/9/10） | **+5（约会对象·额外加成）** | ✅ |
| 真心话环节回答（Day 11） | **+3（回答涉及的对象）** | ✅ |
| 小礼物系统 | **+5~8（收礼者）** / -1（未收礼者·固定） | ✅ |
| 主动降低X好感度 | **-5~10（特定选择可降低X好感度）** | ✅ |

**减值调整说明**：
- 未选中者好感度减值调整为 -0~1（有时不减），减少玩家压力
- 某些选择可以主动降低X好感度（如「明确表示不想复合」「拒绝X的靠近」），让玩家有更多控制权

### 16.4 好感度标记

- AI 每段输出末尾**必须**包含好感度标记：`[好感度: 成员名 +2, 原因: 简述原因]`
- 原因必须**具体可感知**——如「你注意到他抿嘴的动作」「你在他讲冷笑话时笑了」「你主动坐到了他旁边」，禁止写「因为你选择了相关选项」等模糊原因
- 解析器提取后：更新数值 + 写入日志 + **从正文中删除**（不显示）
- 标记放在 `【选项】` 之后，不在正文中

### 16.5 好感度面板

- Header 好感度图标行点击弹出
- 每位成员显示当前好感度 + 最近 **3 条**变化记录（含增减）
- 记录格式：Day X 时段：+2 原因 → 总数值
- 增加用绿色（aff-change-pos），减少用红色（aff-change-neg）

### 16.6 好感度里程碑提示

| 好感度达到 | 提示内容 |
|-----------|---------|
| ≥40 | 弹出提示：「💚 他开始在意你了」 |
| ≥60 | 弹出提示：「❤️ 他明显对你有好感」 |
| ≥80 | 弹出提示：「❤️🔥 他深深被你吸引」 |

提示为非阻塞toast样式，显示2秒后自动消失。每位成员只触发一次，不重复提示。

### 16.7 观察员约束

观察员绝对不能提及具体的好感度数值。评论基于观察到的行为和情感，不是数字。

### 17.1 判定逻辑

## 十九、记忆系统 v3.0

### 18.1 同天内

- 不压缩，全部保留在 `todayFullText`
- 超过 8000 字时压缩为 4000 字摘要（`_todayCompressedSummary`）
- **phase 类型使用完整 todayFullText**（当天内容不超过 8000 字），确保 AI 记住今天发生的所有事

| consequence | 采访间摘要 + 今日已揭示信息 + 对话归属提醒 + 纯正文尾部 500 字锚点 + 选项文本 |
| freeAction | 完整原文 + 显式时间锚点（「玩家的行动已执行完毕，当前位置是…」） |
| stay | 完整原文 |
| sms | 完整原文 + 短信内容 |

### 18.4 纯正文尾部锚点

- 过滤 🎬💭🎙🎤🎙️💔 标记行、分隔线、空行、**选项行**（【选项】+ 编号选项）

### 18.5 按钮读取范围

**不读取**：导演 OS（🎬）、观察员 OS（💭）。

### 18.6 记忆审查面板（可折叠非模态面板）

## 二十六、AI 输出格式强制约束（30 条）

1. 正文使用第二人称「你」
2. 正文中绝对不能出现 🎬💭🎙🎤🎙️💔 标记
3. 正文中绝对不能描写女主发送短信的行为
4. 正文不直接描写成员内心想法——通过 🎤 成员采访间或 💭 观察员 OS 呈现
5. 观察员 OS 不可省略，使用多人对话格式
6. 🎙 女主采访间为强制，每段至少 1 次，触发即插入
7. 🎤 成员采访间为强制，每段至少 1 次，触发即插入（与🎙一致）
8. 输出结构：正文→🎙→正文→🎤→...交替穿插，触发即插入。导演OS+观察员OS 放最后

15. ⚠️ 正文中禁止女主深度自我分析和情感反思。正文只写即时生理感受。所有反思必须放在 🎙 标记中

20. ⚠️ 女主 🎙 采访间必须包含对 X 的真实感受
21. ⚠️ 用一句话自然锚定当前位置后紧接着写新内容。不要大段复述

23. ⚠️ 禁止关键词粘合——角色回应应基于对前一句的理解，而非对前一句中某个词的机械匹配

## 二十七、写作风格规范

- 沉浸式恋爱小说+韩综氛围。文艺但不拗口，口语但不随意
- 描写比例：环境~20%、对话~32%、女主心理~15%、肢体细节~20%、成员心理通过采访间和 OS 呈现~13%
- 女主心理精简精准，不过度自我分析。关键时刻留白
- 对话自然口语，符合每个成员人设语气。有潜台词
- 肢体细节：眼神是最重要情感载体。不经意的触碰比刻意更有张力
- 情感浓度递进：Day1-3 克制含蓄 → Day4-7 暗流涌动 → Day8-10 情感爆发 → Day11-12 极致拉扯
- 星座可以作为角色自我认知和轻松话题的参考，但不要变成星座算命节目
- **绝对禁止**：AI 味元叙事、言情小说式夸张比喻、替玩家做情感判断、角色替玩家解读、过度解释、说教式旁白、综艺字幕风对话标注、正文直接描写成员内心、任何抽烟描写、关键词粘合、辈分称谓、韩式敬语后缀

## 二十八、成员间关系约束

### 26.1 既有关系

3 位 SEVENTEEN 成员彼此是多年队友，从 Day 1 起就非常熟悉：
- 自然的默契（接话、补刀、眼神交流、内部梗）
- 随意的语气（直呼名字，不需要敬语和客气）
- 可以调侃、吐槽、翻旧账
- 不需要「初次认识」阶段的试探和自我介绍
- 团内旧事可以自然提及，但不要突然大段回忆——就像真实朋友聊天，偶尔提一句「上次巡演的时候他……」就够了
- 节目中唯一的新人是女主。成员对女主的态度从陌生到熟悉是正常的，但成员之间不存在这个过程
- **禁止成员之间出现「初次认识」式的寒暄**

### 26.2 竞争与默契

2 位攻略对象 + 1 位 X 都在关注女主，但他们也是多年队友：
- 有人可能主动退让（「我觉得他更适合你」）
- 有人可能暗暗较劲（更主动地出现在你身边）
- 这种张力不需要狗血，但需要存在——体现在眼神、时机选择、采访间的坦诚中

### 26.3 称呼规则

- 所有角色之间一律直呼名字（如「圆佑」「珉奎」「胜澈」「沈也」）
- 禁止任何「xx哥」「xx欧巴」等辈分称谓
- 禁止使用韩式敬语后缀「-xi」
- 成员之间用名字互相称呼，体现多年队友的随意感
