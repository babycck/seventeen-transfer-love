■ 0. 这个游戏是什么

你扮演 SEVENTEEN 某位成员的亲妹妹（队友的妹妹），开局身份为 练习生（出道后自动晋升为女团爱豆）。开局时你和哥哥的队友——也就是日后的心动男主（SEVENTEEN 成员）——只是同行业前辈与后辈的关系，是否通过哥哥见过面都未可知。一切从零开始，在聚光灯下缓慢酝酿一段 地下恋。

核心张力只有一句话：谈恋爱会掉粉，不谈又憋屈。你要在「事业上升」与「恋情保密」之间走钢丝：约会、告白、营业 CP、粉丝经济、狗仔与站姐、亲哥的审视，全部交织在一起。

- 玩家视角：第一人称，AI 实时生成剧情文本
- 回合制：点「进入下一天」推进 1 天 = 1 个剧情小节（round）。同一天内可自由互动（选项 / 聊天 / 约会 / 探班）不推进时间；顶部 Header 显示的「上午 / 下午 / 夜晚」只是场景氛围标签，不影响推进。
- 目标：把事业做到顶流，把恋情走到想要的结局（公开 / 地下 / 单身封神……共 9 种，含 1 隐藏）

■ 1. 快速开始（5 步开局）

│ 步骤 │ 界面 │ 你要做什么 │
│ ① 选模式 │ 首页 │ 点「娱乐圈模拟器」🌟 卡片，进入专属开局流程（世界观锁定为娱乐圈） │
│ ② 选人与设人设 │ 选心动对象 + 女主设定 │ 选 1 位 SEVENTEEN 成员当男主；身份固定为「队友的妹妹」，职业固定为「练习生」（出道后晋升女团爱豆）。哥哥和情敌由系统随机从剩余成员中抽选，每次新开档都不同 │
│ ③ 选风格 │ 世界观（锁定）+ 写作风格 │ 娱乐圈世界观不可改；选写作风格：甜宠 / 现实 / 慢热 / 热烈 等 │
│ ④ 确认并开局 │ 确认页 │ 核对信息 → 开始游戏 │
│ ⑤ 进入游戏 │ 自动 │ 系统生成真实日历（2024-01-01 起，支持闰年），自动产出第一段剧情 │

  ▹ ⚠️ API 设置：本模式依赖 AI（DeepSeek）。开局前需在设置里填好 apiKey / 模型。没有可用 API 时游戏无法生成剧情。

开局后系统会做几件重要的事（你无需操作，但要知道）：
- 固定好感开局为 0（慢热，两人只是前辈与后辈的陌生人关系）
- 开局不默认「已经通过哥哥认识」，男主称呼不带「妹妹」
- 男主种子事件延迟生成：好感≥5 或回合≥3 时才触发，避免开局就预设男主心动
- 哥哥从剩余12人中随机的（randInt），情敌从排除男主+哥哥后的11人中随机（Math.random），每次新开档不同
- 开局固定生成 5 位姐姐队友（化名 + 性格标签 + 关系标签，所在 6 人小糊团）
- 女团极度团结：队友之间有矛盾是正常的，但不会出现阴阳怪气、恶意抢 part、翻白眼等破坏团魂的行为

■ 2. 界面导览

游戏主界面是三栏等高布局：左栏（团设卡片 / 最近活动 / 日程 / 队友 / 曝光）、右栏（热搜 / 媒体热议 / 粉丝讨论 / 恋情面板），中栏（剧情 + 选项 + 自由输入 + 恋爱按钮 + 快捷指令）；三栏下方内联 6 个 Tab（居中装在圆角框内）。剧情生成后自动滚动到最新内容。

● 顶部 Header（左→右）
- 标题：💗 地下恋 · Day X 时段（「时段」仅氛围标签，不推进时间）
- 章节徽标：图标 + 章节名（如 🌱新人出道 / 🚀稳步上升），无序号
- 恋爱阶段徽标：图标 + 当前阶段名（如 🌿相识 / 💗心动），随好感实时变
- 右侧：人气 数字(层级如「走红」) / 好感 X/100 / ⚙️ 设置

● 左栏：团设 / 最近活动 / 日程 / 队友 / 曝光
- 团设卡片：显示女团全名、所属社（独立一行）、概念风格（独立一行）、粉丝名、出道年限、出圈歌曲
- 📋 最近活动：出圈曲下方分行展示近 30 天团队动态（📀发布 / 🎬综艺 / 🏆获奖 / 📸画报 / 💼代言 各一行）
- 今日日程：主档 🎤 / 男主档 💜 / 相关档 📺 / 情敌档 💢 / 哥哥档 👨 五档，每档带地点标签
- 女团队友：5 位姐姐按钮（点击先弹确认框：显示姓名+职位+性格标签，确认后触发AI支线剧情）
- 曝光档位：实时显示当前曝光阶梯（🟢安全 → 🟡暗涌 → 🟠升温 → 🔴哗然 → ⛈️引爆）

● 中栏：剧情主体
- 剧情文本（AI 生成，严格锁定在今日日程设定的场景内）
- 时段写作指引：上午偏练习/工作、下午偏社交/营业/互动、夜晚偏私密/独处/约会
- 选项按钮（每段 2–6 个分支，点击后先弹预览标签：💞亲密互动 / 👨涉及哥哥 / 💢涉及情敌 / 📸曝光风险 / 🛡️回避 / 🎤事业相关 / 💬联络，并显示预估风险评分与粉丝流失数，确认后才推进）
- 自由输入框（底部，可输入任意台词/行动）
- 恋爱动作按钮：💞约会(好感≥30) / 💍告白(好感≥80 且哥哥非反对+非冷战+未告白过) / 🌟进入大结局(好感满100 且 ≥10 轮)

● 右栏：今日圈内 / 恋情面板
- 今日圈内：每日舆论流（🔥热搜 / 💬粉丝讨论 / 📰媒体热议），热搜仅 1 条与女主有关（AI 生成），粉丝讨论与媒体热议全部来自 pools/ 池子
- 📱 营业面板（按钮显示「手机 · 泡泡X/5」）：打开后手机浮层——📞Kakao聊天 / 💬泡泡 / 📊反馈 / 📝日记 四页
- 恋情面板：关系阶段 + 好感度（可点击查看完整变动日志） + 亲密图标 + 曝光值 + 掩护次数 + 哥哥支持度
- 🎭 剧场按钮：点击打开番外剧场（按好感解锁 6 种类型）
- 🌟 结局按钮：点击进入结局判定

● 中栏内快捷指令

上行（工作线）：📬信箱（🆕有未读）/ 🏆奖项 / 💼代言 / 🎬综艺 / 📸画报 / 📀发布CD

下行（行动线）：重新生成 / 下一个行程 / 🛡️掩护(X/5) / 随机事件 / 探班 / 下一天

冷却规则（代言/综艺/画报/CD 有冷却时间，冷却中按钮灰化+倒计时显示）：
│ 工作 │ 冷却 │ 说明 │
│ 💼 代言 │ 3 天 │ 品牌邀约频率高，短平快 │
│ 🎬 综艺 │ 5 天 │ 录制周期稍长 │
│ 📸 画报 │ 3 天 │ 拍摄类可高频接 │
│ 📀 CD/发布 │ 7 天 │ 作品发布需间隔 │

日程事件系统：点击工作按钮 → 弹出确认弹窗（展示具体内容和奖励）→ 接受后排入明日日程 → AI 自动生成工作场景剧情 → 完成后自动结算人气和曝光。

● 三栏下方内联 6 Tab（居中分散，装进圆角框）
- 剧情（主界面）
- 聊天（与男主实时对话，带「正在输入」动画，每天限 20 条，每 5 条+1 好感最多 3/天。快捷回复按钮：男主频道从 CHAT_MALE_LEAD 真实对话池取 q 值，与回复匹配同源；哥哥/情敌频道按阶段池取）
- 朋友圈（双视角动态：女主发帖+男主发帖，情敌随机评论）
- 剧场（番外故事，按好感解锁：男主视角 / 情敌 IF≥20 / 校园 IF≥35 / 哥哥视角≥50 / 婚后 IF≥70 / 回忆录≥80）
- 日记（双视角碎片：女主日记+男主日记，每 3 回合自动生成一对）
- 信箱（秘密信件，每 7-10 回合自动收到一封男主 200 字第一人称手写信）

■ 3. 核心数值速查

● 3.1 人气（career.popularity，0–100）
事业的根本。练习生期人气=0（未出道=无公众曝光），出道后（debutDay 置位）由 startPopularity（默认 12）起步。人气没有每日固定衰减，由营业/互动/作品/曝光等剧情事件增减。

  两套等级系统不要混淆：「事业等级标签」(careerLevel, 6档) 是纯 UI 显示文字；「章节阶段」(chapter, 6阶段) 是游戏进度控制——决定日程池/热搜/弹窗是否触发。练习生另有 3 子阶段以天数驱动。

A. 事业等级标签（careerLevel，UI显示用，6档）：

│ 人气 │ 标签 │ 含义 │
│ 0-14 │ 新人 │ 刚起步 │
│ 15-34 │ 上升 │ 有起色 │
│ 35-54 │ 走红 │ 有了姓名 │
│ 55-74 │ 当红 │ 资源主动找上门 │
│ 75-89 │ 顶流 │ 焦点人物 │
│ 90-100 │ 传奇 │ 封神 │

B. 章节阶段（chapter，出道后 6 阶段）：

│ 人气 │ 章节 │ 图标 │ 日程池 │ 说明 │
│ —（天数驱动）│ 练习生 │ 🌱🌿🌸 │ 3 子阶段池(各 30 条) │ 未出道，人气=0，仅训练（详见 §4） │
│ 0-14 │ 新人出道(Ch1) │ 🌱 │ CHAPTER1_NOVICE(50条) │ 刚出道小糊团，资源少冲劲足 │
│ 15-34 │ 崭露头角(Ch2) │ 🌿 │ CHAPTER2_SPROUTING(30条) │ 有了第一批死忠粉，打歌能进候补 │
│ 35-54 │ 稳步上升(Ch3) │ 🌸 │ CHAPTER2_RISING(50条) │ 粉丝稳定增长，品牌开始关注 │
│ 55-74 │ 人气偶像(Ch4) │ 🔥 │ CHAPTER3_PEAK(50条) │ 热搜常客，代言不断，回归必拿一位 │
│ 75-89 │ 顶流巨星(Ch5) │ 👑 │ CHAPTER5_TOPSTAR(30条) │ 国民级热度，巡演场场秒空 │
│ 90+ │ 传奇殿堂(Ch6) │ 🏆 │ CHAPTER4_LEGEND(50条) │ 封神之后，后辈仰望的传说 │

  章节只进不退。出道由天数驱动（练习生后期 2-4 天内自动触发「出道最终评价」事件），出道后由人气阈值自动推进。日程 70% 章节池 + 30% 通用池。

● 3.2 今日圈内（舆论活跃度）
右栏「今日圈内」的舆论条数：🔥热搜约 3 条（仅 1 条与女主有关）、💬粉丝讨论固定 3 条（全外部）、📰媒体热议固定 2 条（全外部）。女主相关条目可点展开 AI 生成评论；非女主条目直接展示池子评论。

● 3.3 好感度（romance.affection，0–100）与关系阶段
好感度驱动一切恋爱进展。AI 每回合可能返回 ±1-3 的好感变化，但仅限男主实际出场并与女主有实质互动的回合；女主独角戏（刷热搜/看手机/练习/与队友闲聊）或男主仅作为背景板出现的回合，好感不会变动。界面用 8 档细标签显示当前阶段：

│ 好感 │ 阶段标签 │
│ 0 │ 初遇 │
│ 20 │ 相识 │
│ 35 │ 好感 │
│ 50 │ 暧昧 │
│ 60 │ 心动 │
│ 70 │ 追求 │
│ 80 │ 交往 │
│ 90 │ 陷入恋爱 │

  结局判定用 6 档「关系深度 depth」：初遇(0) / 暧昧(20+) / 暧昧明朗(35+) / 恋情(50+) / 浓情(60+) / 公开(80+)。

心动时刻：好感跨越 60（暧昧→心动）时，自动插入约 300 字沉浸式高光描写（仅 1 次）。
好感里程碑卡片：好感达到 20/40/60/80 四个阈值时，自动弹出固定文案的纪念卡片（纯代码控制，不依赖 AI）。
人气飘字动画：每次人气增减时，屏幕会飘出 +N（绿色）/ −N（红色）浮动文字（持续 1.3 秒自动消失）。

● 3.4 曝光（misc.exposureAccum，唯一真值源）
地下恋的「危险值」。每次约会、营业掩护、试探心意、高风险选项都会累加。

│ 累计值 │ 档位 │ 说明 │
│ <5 │ 🟢 安全 │ 低调可控 │
│ 5 │ 🟡 暗涌 │ 暗流涌动 │
│ 10 │ 🟠 升温 │ 曝光升温 │
│ 15 │ 🔴 哗然 │ 舆论哗然 │
│ ≥25 │ ⛈️ 引爆 │ 彻底曝光·塌房边缘 │

  达到引爆（≥25）会让恋情面临「被迫公开抉择」；结局判定会按 tier 分档（安全 / 升温·暗涌 / 哗然·引爆）。
  每日自动衰减：每次「进入下一天」时，曝光累计值自动 ×0.7（衰减 30%）。所以只要不连续作死，曝光值会逐渐回落。
  ⚠️ 公司高压线：若曝光达到 80，公司直接扣你 −5 人气（公关危机成本），每超标一天扣一次。

● 3.5 哥哥支持度（brotherSupport，−100 ~ +100）
你亲哥对你恋情的立场。影响掩护手段可用性与结局走向。
  ⚠️ support 是连续值 −100~+100；而立场（stance）不由 support 数值派生，由哥哥事件 / AI 独立设置（开局为「参谋」）。常见立场如：参谋 / 反对公开 / 认可掩护 / 退出祝福 等。只有「反对公开」会卡住告白（见 §5.2）。

● 3.6 关系网立场
4 类 NPC 各有立场（护你 / 吃瓜 / 回踩 等），随互动漂移，直接影响曝光与资源。

■ 4. 时间、章节与小节

- 一天 = 1 回合（round）。唯一推进方式是点「进入下一天」（dayCount 与 roundTotal 同时 +1）。顶部 Header 的「上午 / 下午 / 夜晚」只是场景氛围标签。
- 小节（round）：每生成一个剧情段 = 1 小节。
- 阶段：共 9 状态（练习生 3 子阶段 + 出道后 6 阶段）。练习生按天数驱动，出道后按人气阈值自动推进。

练习生 3 子阶段（人气=0，天数驱动）：

│ 子阶段 │ 图标 │ 天数 │ 氛围 │ 日程池 │
│ 前期 │ 🌱 │ day 1-4 │ 刚进公司，基础训练，迷茫 │ TRAINEE_EARLY_POOL（30条） │
│ 中期 │ 🌿 │ day 5-10 │ 适应节奏，月末评价，同期竞争 │ TRAINEE_MID_POOL（30条） │
│ 后期 │ 🌸 │ day 11+ │ 出道组筛选，出道曲排练，紧张期待 │ TRAINEE_LATE_POOL（30条） │

  出道触发：进入后期 2-4 天内自动触发「出道最终评价」事件 → debutDay 置位 → 人气 = startPopularity（默认 12）→ 左侧团卡/队友/热搜/星圈全部解锁。

出道后 6 阶段（人气驱动）：

│ 章 │ 名称 │ 图标 │ 人气 │ 氛围 │ 日程池 │
│ 1 │ 新人出道 │ 🌱 │ 0-14 │ 刚出道小糊团，打歌/新人综艺/签售等 │ CHAPTER1_NOVICE（50条） │
│ 2 │ 崭露头角 │ 🌿 │ 15-34 │ 有了死忠粉，圈内有名字 │ CHAPTER2_SPROUTING（30条） │
│ 3 │ 稳步上升 │ 🌸 │ 35-54 │ 粉丝稳定增长，综艺商演不断 │ CHAPTER2_RISING（50条） │
│ 4 │ 人气偶像 │ 🔥 │ 55-74 │ 热搜常客，代言不断 │ CHAPTER3_PEAK（50条） │
│ 5 │ 顶流巨星 │ 👑 │ 75-89 │ 国民级热度，恋爱即成核弹 │ CHAPTER5_TOPSTAR（30条） │
│ 6 │ 传奇殿堂 │ 🏆 │ 90+ │ 封神之后，恋情成大众祝福 │ CHAPTER4_LEGEND（50条）

- 章节跨越奖励：每次跨入新章节，+1 掩护次数上限（基础 5→6→7 封顶）。
- 每日自动事件：每推进一天，自动触发一次事件（7 级优先级瀑布：男主小动作每 5-8 回合 / 哥哥递进考验 / 情敌主动 / 秘密撞破 15% / 哥哥支线 12% / 女团事件 25% / 队友支线 22%；只取最高命中的 1 条）。所有事件池仅出道后触发（isDebut门控），练习生阶段只触发哥哥/队友/练习生剧情。
- 剧情选项中有时会带风险预估徽标：高风险选项会标注「粉丝 −N」。
- SEVENTEEN 回归期：每 15-20 天随机触发一次，持续 5-7 天。期间男主行程密度极高、可约时间大幅减少；但同台打歌场景概率大幅增加。
- 换天过渡：点「进入下一天」时全屏遮罩显示「新的一天 · DayX」→淡入；章节跨越时全屏光效 + 章节名牌；每天结束后弹出每日结算弹窗。

■ 5. 玩法系统详解

● 5.1 剧情推进
- 选项：每段剧情给 2–6 个分支。点击后先弹预览（标签+风险评分+粉丝流失预估），确认才推进。
- 自由输入：底部输入框写任意台词/动作，AI 据此生成反应。
- 重新生成：回滚上一条剧情，用同样条件重新生成（带确认弹窗）。网络错误时 generateWithRetry 自动重试 3 次（指数退避），全失败后显示「剧情生成失败，请点击选项重试」+ 「重试」按钮。
- 随机事件：手动触发一个随机事件。
- 掩护：🛡️ 按钮嵌入快捷指令行，点击弹出 5 种掩护手段面板。
- 探班（快捷指令）：借口工作溜去男主所在的待机室/休息室相处。点击后弹出确认框（显示行程+风险提示+「确定」「取消」按钮，使用 Promise 异步确认）。
- 进入下一天：最关键的「推进键」——换天过渡动画→清理冷战/告白冷却→曝光衰减 30%→重置每日 NPC 互动→刷新舆论流→触发营业事件→触发哥哥事件与男主主动→推进章节（跨章播全屏光效）→弹出每日结算。

● 5.2 恋爱系统
- 约会（好感 ≥ 30 解锁）：6 种场地（私人影院 / 深夜江边 / 他家 / 车里 / 天台 / 地下停车场）。效果固定为：好感 +3、曝光累计 +1。
- 告白（好感 ≥ 80 解锁）：需同时满足 ①好感 ≥80 ②哥哥非反对公开 ③当前非冷战 ④尚未告白过。
  - 接受 → 好感 +10、哥哥支持度 +5，仍维持地下恋（不自动公开）
  - 拒绝 → 好感 −10、进入冷战 2 回合、情敌亲密 +15
  - 注意：若累计告白被拒 2 次，之后不再出现主动告白按钮
  - 拖延 → 好感不变、告白冷却 5 轮、哥哥支持度 −3 并触发哥哥找你谈话
- 掩护手段（见 §5.3）

关系网互动（每日 1 次机会，降曝光 / 拉人气）：

● 5.4 关系网（NPC）
4 类 NPC 各有事件池，每日自动或手动互动 1 次，影响：
- intimacy（亲密）：与你的关系亲疏
- stance（立场）：护你 / 吃瓜 / 回踩 / 试探 / 退出祝福 等
- exposure（曝光）：该事件带来的实锤风险（正值升危）

关键 flag：rivalQuit（情敌退出）、suitorQuit（男主的情敌退出）、contractRead（读过恋爱禁令合约）等。

● 5.5 哥哥系统（核心张力）
哥哥是你亲哥、男主队友，三重身份：哥哥 / 队友 / 情敌队友。
- 支持度 −100~+100（见 §3.5），靠你的选择累积；立场由 AI 在剧情中通过哥哥反应设定（开局「参谋」），不是由数值派生、也不是失败后自动转反对。
- 哥哥把关（考验）：好感 ≥15 / ≥40 / ≥70 依次解锁第一 / 二 / 三次把关事件；触发并通过时支持度 +3 / +5 / +8。
- 哥哥支线：创作瓶颈 / 黑粉事件 / 队友矛盾（轻，不影响关系，纯氛围）。
- 哥哥发现秘密：会调侃你（每隔几回合）。
- 哥哥被情敌牵动：哥哥对情敌的察觉在「情敌退出祝福（rivalQuit）」时触发（rivalAware=true，哥哥私下警告情敌、夹在两人中间为难）。

● 5.6 女主秘密

■ 8. 玩法策略与技巧

● 8.1 曝光控制（最重要）
- 铁律：把 exposureAccum 压在 <5（安全）。每次约会固定 +1，连续约会极易破 10。
- 约会后必掩护：用 🤐假装不熟 / 👨借哥掩护 不增 suspicion，但各扣哥哥 −3。
- 避嫌约会 🚫：约会质量+但 suspicion+1，多次使用会让站姐转「吃瓜」——别连用。
- 营业掩护 📺：推高情敌亲密，只在你想养情敌线时用。
- 日常降曝光：每天找经纪人「谈话稳住」（−2 曝光）、对情敌「示好」（−1）、对男主的情敌「保持距离」（−1）。
- 引爆（≥25）后果：恋情被迫公开抉择，或直接在结局判定里走「塌房」BE。

● 8.2 好感推进路线
1. 前期（好感 <30）：靠剧情选项、聊天、自由输入铺垫；让男主「上心种子事件」慢慢发酵。
2. 中期（30–60）：解锁约会后，用 6 种场地稳定 +3（固定）；触发心动时刻（≥60）是高光节点。
3. 后期（60–80）：保持约会 + 哥哥把关通过（好感 15/40/70 三关），攒到 80 即可告白。
4. 告白后：接受后维持地下恋（好感 +10、哥哥 +5）；想拖可拖延（冷却 5 轮），好感不变、哥哥 −3 并找你谈话。

  ⚠️ AI 每回合不会无条件加好感。只有男主实际出场并与女主有实质互动时才会产生好感变化（±1–3）。刷热搜、看手机、练习、与队友闲聊等独角戏回合好感不会变。想推进好感，优先约会/探班/聊天/男主在场的选项。
  好感不自动衰减；人气也无每日固定衰减，但部分事件会大跌。

● 8.3 哥哥攻略
- 哥哥支持度从 0 起步（连续值 −100~+100），尽量保持为正。
- 别滥用掩护：🤐/👨 每次各扣哥哥支持度 −3。
- 过三关：好感 15/40/70 的把关分别 +3/+5/+8，顺其自然别刻意避开。
- 哥哥支线：创作瓶颈/黑粉/队友矛盾纯氛围，参与即可，不影响关系。

● 8.4 关系网经营
- 站姐是你人气的命门：每天「讨好稳粉」+2 人气，别让她「回踩」（一旦回踩，曝光 +3）。
- 情敌 / 男主的情敌：示好/保持距离都能 −1 曝光，但「试探心意」+1 曝光。
- 经纪人：前期求资源拉人气，后期谈话稳住降曝光，性价比最高。

● 8.5 结局攻略速记
- HE 公开婚礼：好感 ≥80 + 曝光全程安全（最难，需精确控曝光）。
- HE 地下永久：好感 ≥60 + 曝光安全（最稳的圆满）。
- HE 独美封神：全程不恋/低好感 + 把人气冲到传奇/巅峰（事业线玩家）。
- 隐藏情敌结局：养情敌亲密到 ≥50，同时保持对男主好感 <40。
- 避坑：好感 ≥60 却把曝光冲到引爆 → 直接 BE 曝光塌房；想单身却没冲人气 → NE 独自前行。

● 8.6 小技巧
- 记忆回顾可编辑：当天剧情和历史压缩记忆都能直接修改并保存。
- 泡泡每天最多 5 条：是维持粉丝黏性的低成本方式，连续发可累积 streak 天数。
- 营业面板双 Tab：💬泡泡发消息给粉丝，📊反馈看所有历史粉丝圈反应（大粉/路人/黑粉三色卡片）。
- 选项预览别跳过：每次选择前先看标签+风险评分，避免盲选高风险选项。
- 每日结算换天时自动弹出：快速确认当天人气/曝光/好感三项净变动。
- 自由输入是补选项盲区的最佳工具：想说选项没有的话，直接打。
- 重新生成回滚上一段：对 AI 生成的剧情不满意，点「重新生成」用同样条件重试（需确认）。

■ 9. 常见坑点与 FAQ

Q：为什么点不了「约会」？
A：好感需 ≥30 才解锁。前期先靠选项/聊天铺垫。

Q：为什么点不了「告白」？
A：需好感 ≥80，且哥哥非「反对公开」、当前非冷战、尚未告白过。好感不够或哥哥在反对态都会灰化。

Q：曝光一直涨，怎么办？
A：每天用经纪人谈话(−2)、情敌示好(−1)、竞争者保持距离(−1) 压；约会后用 🛡️ 掩护；别连续约会。

Q：哥哥突然变「反对」了？
A：哥哥立场由剧情中他的反应决定（AI 设定）；掩护用太多会扣哥哥支持度、告白拖延也会 −3，支持度长期偏低时更易在剧情里被写成「反对公开」。减少掩护频率、过好三关把关，支持度会回来。

Q：人气怎么掉了？
A：entSim 中人气没有每日固定衰减，掉通常是由具体事件/选项造成（如恋情曝光反噬按严重度扣 严重度×7、高风险选项粉丝流失等）。看「人气变动日志」能定位原因；靠营业、互动、作品回升。

Q：为什么剧情里总有姐姐？
A：5 位姐姐是你所在 6 人女团的队友，开局固定生成。她们很团结，不会阴阳怪气或恶意抢 part。左栏可直接点击触发队友支线。

Q：探班被拍了？
A：探班若与男主的情敌档口重合会撞见并 +曝光。探班前看右栏行程，避开情敌档。

Q：能切换男主吗？
A：不能中途换。职业固定为女团爱豆、本就不可选；男主也需「重置游戏」重新开局（见 §10）。

Q：和「换乘恋爱」「只为你心动」的区别？
A：换乘恋爱是 3 人修罗场 12 天；只为你心动是纯 1v1 恋爱；本模式是娱乐圈职业 + 地下恋 + 事业经营 + 哥哥/队友/粉丝生态，系统最重。

Q：泡泡是什么？和聊天有什么区别？
A：泡泡是给粉丝发的付费订阅广播（右栏「📱营业」按钮 > 💬泡泡 Tab），AI 会生成粉丝回复；聊天是跟男主的私聊（底部 Tab 栏「聊天」）。两个完全不互通。

Q：为什么剧情里不能写我在 SEVENTEEN 群里？
A：因为你不是 SEVENTEEN 成员，天然不在他们的内部工作群。这个规则已写死在 AI prompt 中。你只有女团姐妹群。想知道 SVT 群内容？只能靠哥哥亮手机/队友转述/临时协作群 3 种方式。

Q：怎么知道选项安不安全？
A：点击选项后会先弹预览面板，显示影响标签、风险评分、预估粉丝流失。确认才推进，不确认可换选其他分支。养成「先看预览再选」的习惯。

Q：哥哥和情敌是谁？是我自己选的还是随机的？
A：只有男主是你自己从 13 人中选的。哥哥由系统从排除男主后的 12 人中随机抽选（randInt），情敌从排除男主+哥哥后的 11 人中随机抽选（Math.random）。每次新开档，哥哥和情敌都会重新随机，不固定。

■ 10. 存档与重置

- 自动存档：每次关键操作（推进、约会、告白、掩护等）自动写入 localStorage（local_game_state）。关掉网页再开通常能续上。
- API 设置 / 主题 / 打字机速度：重置时保留，不会丢。
- 重置游戏：在设置或首页选择「重置」，会清空当前进度回到开局；API key、主题、速度等用户偏好保留。
- 不建议手动改存档：entSim 字段结构复杂，手动改易出错。

■ 11. Prompt 架构：A/B/C 三分区 + 剧情生成规则

这是本游戏最核心的架构设计——「尽量让 AI 少判断，只做剧情输出」。所有日期/季节/天气/生日/节日/行程/感情状态/角色出场等硬事实由代码 100% 预计算后直接注入 prompt；软调味从池子抽取；AI 只负责扩写正文 + 3 选项 JSON。

● 11.1 真实日历系统

dayCount=1 → 2024-01-01，DAYS_IN_MONTH=[31,28,31,30,31,30,31,31,30,31,30,31]，支持闰年判断 (_isLeapYear)。二月正确输出 28/29 天，不会出现「2 月 30 号」。季节判定：冬=12,1,2 / 春=3,4,5 / 夏=6,7,8 / 秋=9,10,11。

formatGameDate(dayCount) → 「2024年3月14日」等真实日期。

● 11.2 A区·硬事实（代码 100% 预计算，AI 只读不编）

由 buildHardFactsBlock(E, extra) 生成，6 个子块：

A1 今日基础：日期·季节·天气·体感温度·时段
    如：「2024年6月15日 · 夏季 · 晴 · 体感炎热 · 上午」

A2 今日特殊：核心角色生日·节日·SVT队友今日寿星·13人生日参考表
    svtBirthdayInfo(dayCount) 返回：「今天过生日的SEVENTEEN成员：全圆佑(7月17日) | 参考表：崔胜澈 8/8 | 尹净汉 10/4 | ...」
    SVT 13 人真实生日数据来自 svt-teammate-profiles.js（含 birthMonth/birthDay 字段）

A3 今日行程：上午主档/下午副档/晚上/职业阶段/练习生或出道
    如：「上午：打歌舞台(待机室) | 下午：综艺录制(电视台) | 晚上：自由 | 已出道·崭露头角」

A4 感情状态：好感度·恋爱阶段·叙事模式·男主情绪·哥哥立场/支持度·情敌·冷战/吃醋·曝光风险
    如：「好感35 · 暧昧期 · 哥哥支持3 · 情敌亲密度8 · 哥哥立场：参谋」

A5 今日可见角色：哥哥(位置) · 男主可见/仅在背景
    如：「哥哥崔胜澈(练习室) · 男主全圆佑可见」

A6 阶段行为限制：允许做什么/禁止做什么（正面陈述，不含负面禁止清单）
    如：「允许：观察/群聊/哥哥互动 · 禁止：男主主动/二人独处/专属暗示」

● 11.3 B区·软调味（代码从池子抽 1-2 条，AI 自然融入）

由 buildSoftFlavorBlock(E, extra) 生成，5 个子块：

B1 日历氛围（仅每日首回合注入，防同天重复）：
    从 CALENDAR_ATMO_POOL[month][day] 确定性索引，365 条覆盖全年。如：
    「六月练歌房都开着门，路过每扇门都是不同的旋律，像一盒随机播放的CD。」

B2 今日心情：
    从 ATMOSPHERE_MOOD 池按好感度过滤取 1 条。如：「有些疲惫但很充实」

B3 日常插曲：
    从 DAILY_DETAIL_POOL 按当前场景类型过滤取 1 条（24 条覆盖练习室/走廊/休息区/电梯/食堂/便利店/天台/公司门口/录音室/声乐教室/通用），无匹配跳过。
    如：「走廊里有人在聊第二天的打歌舞台，声音传到练习室这边来断断续续的。」

B4 手机角落：
    _entSimChatHistory 最后消息摘要 + bubble 今日计数。开局无聊天记录时兜底「手机安静，暂无新消息」。

B5 五类记忆（buildMemoryByType）：
    careerHistory 按 type 分组取最近 1-2 条，附当前数值：
    「近期记忆·分类 | 感情(好感35)：前天打歌结束他来后台看了你一眼 | 事业(人气28)：品牌画报拍摄顺利完成 | 哥哥(支持3)：哥哥说最近练习太狠让你多休息 | 情敌(亲密度8)：情敌在签售会上多看了你一眼 | 其他：暂无」

● 11.4 C区·AI 创作

AI 在接收 A 区硬事实 + B 区软调味后，输出：
- 正文 400-700 字（日常回合）/ 700-900 字（关键事件：告白/约会/生日等）
- 3 个选项，JSON 格式，extras 含 affectionDelta / romanceBeat / npcEncounter / exposureEvent / brother / endingsHint / appointments
- 一天 3 回合（上午/下午/晚上），narrative buffer 上限 10000 字自动折叠
- temperature: 0.55，maxTokens: 5000（DeepSeek v4 pro 适配）

● 11.5 字数控制规则

│ 场景类型 │ 正文字数 │ 说明 │
│ 日常回合 │ 400-700 字 │ 上午/下午/晚上的普通剧情推进，练习/工作/社交场景 │
│ 关键事件 │ 700-900 字 │ 告白/约会/生日/哥哥考验/情敌进攻/秘密撞破等高光节点 │
│ 选项数量 │ 3 个 │ 每段固定 3 个选项，不随字数变化 │

● 11.6 禁止规则（已精简为正面引导）

已删除旧版 25 行负面季节禁止规则（如「禁止初雪」「禁止樱花」等），改为 B1 日历氛围正面引导。AI 只需阅读 A 区硬事实中的日期/季节/天气，B1 的氛围提示会自然引导 AI 写对场景。仅保留以下少量负面规则：
- 天气禁制：非雾天禁止雾/雾气描写
- 公共场合禁制：禁亲密举动
- 写歌禁制：好感 <60 或未进入暧昧期禁写歌
- 哥哥禁制：不直接写哥哥的内心独白
- 独处禁制：好感 <30 禁二人独处

● 11.7 重新生成机制

点「重新生成」→ 弹出确认框 → GS._entSimCurrent = null（清空当前 narrative）→ 用相同条件重新调 generateEntSimRound → AI 全新生成一段。
网络错误时 generateWithRetry 自动重试 3 次（指数退避 1.5s/3s/6s），全失败后设 fallback：显示「剧情生成失败，请点击选项重试」+「重试」按钮。
