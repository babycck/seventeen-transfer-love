================================================================================
一、文件夹结构（在 SEVENTEEN 项目根目录下创建）
================================================================================

SEVENTEEN\
├── SEVENTEEN.html              ← 游戏主程序
├── SEVENTEEN.txt               ← 规则书
├── 优化与增加项清单.txt
├── 图片资源落地方案.txt        ← 本文件
└── images\                     ← 【你创建此文件夹】
    ├── bg\                     ← 场景背景图
    ├── members\                ← 成员立绘/头像（支持透明底 PNG）
    ├── cg\                     ← 关键剧情 CG（全屏插图）
    └── items\                  ← X 记忆物品、小礼物等特写

说明:
- 所有图片统一放在 images 目录下，按类别分子文件夹。
- 代码层将使用相对路径引用，如: images/members/scoups_smile.png
- 本地 file:// 协议打开 HTML 时，同一盘符下的相对路径不会被浏览器拦截。

四、图片插入形式（代码可实现的展示方式）
================================================================================

以下形式可多选组合，请勾选你偏好的方式，后续代码按勾选实现:

[ ] 1. 剧情内嵌插图
      在叙事文本中间插入，占卡片宽度 70%-80%，圆角阴影。
      类似轻小说插图效果，不打扰阅读节奏。

[ ] 2. 全屏 CG 事件
      遮罩层覆盖整个屏幕，显示大图，点击或 3 秒后自动收起。
      类似 Galgame 的 CG 回放，用于最高光时刻。

[ ] 3. 背景底图
      叙事卡片半透明浮在背景图上，文字区域加毛玻璃/遮罩保证可读性。
      适合客厅、厨房等常驻场景的氛围营造。

[ ] 4. 角色立绘侧边
      叙事框左侧或右侧浮现当前焦点成员的半身像。
      成员切换说话时立绘跟随切换，增强对话感。

[ ] 5. 物品弹窗
      点击文字中的物品名（如「那条手链」「那张照片」），弹出大图浮层。
      关闭后回到原位置，不打断剧情。

[ ] 6. 顶部/底部横幅
      在卡片顶部或底部插入细横幅图（如日落、街景），不占主空间。

[ ] 7. 头像气泡
      对话式剧情中，成员头像以小圆形出现在段落旁，标识当前说话人。

五、技术注意事项
================================================================================

1. 图片格式建议
   - 立绘/头像/物品：PNG（支持透明底，边缘干净）
   - 背景图/CG：JPG 或 WebP（体积小，加载快）
   - 统一建议尺寸：
     * 立绘：500×700 px（半身像）或 300×300 px（头像）
     * 背景：1280×720 px 或 1920×1080 px
     * CG：1280×720 px 或更高
     * 物品：400×400 px

2. 浏览器兼容性
   - 现代浏览器（Chrome / Edge / Firefox）均支持 file:// 协议下的本地图片加载。
   - 只要 images 文件夹与 SEVENTEEN.html 在同一磁盘且相对路径正确，无需服务器。

3. 部署迁移
   - 本方案采用相对路径（images/...）。
   - 若后续部署到网站，直接上传整个文件夹即可，路径无需修改。

4. 缺失图片容错
   - 代码层会处理图片不存在的情况（如文件缺失），此时静默跳过，不影响游戏流程。
   - 你可以边玩边补充图片，无需一次性准备齐全。
