# 《换乘恋爱 × SEVENTEEN》使用说明

## 一、快速开始

1. 打开游戏：浏览器访问游戏地址
2. 输入 API Key：点击 ⚙️ 按钮填写 DeepSeek API Key（sk-...）
3. 设定女主：输入名字、年龄、职业，选择外貌和性格
4. 选择成员：从 13 人中选 3 位参加节目
5. 标记前任 X：3 人中选 1 位作为你的秘密前任（恋爱 2 年，分手 1 年）
6. 开始游戏：点击「开始游戏！」


## 二、核心玩法

### 12 天节目流程
每天分 4 个时段：

| 时段 | 标签 | 内容 |
|------|------|------|
| ☀️ 上午 | morning | 早餐、日常互动、约会配对日（Day 4/6/8/9） |
| 🌤 下午 | afternoon | 约会场景、延续上午剧情 |
| 🌅 傍晚 | evening | 晚餐、强制任务（读信 / 真心话 / 提问箱） |
| 🌙 深夜 | night | 发短信、继续今天、进入下一天 |

每个时段 AI 自动生成剧情，选择或操作后推进到下一段。

### 三大互动方式

1. **点击选项**：剧情下方出现 A/B/C 选项，点击选择后 AI 生成后续剧情
2. **自由输入**：在底部输入框写下你的行动或想法，点击「✍️ 生成剧情」提交，AI 根据你的输入生成回应
3. **发短信**：深夜时段点击「📨 发送心动短信」发给指定成员

> 每个时段最多可选 3 次（选项 + 自由输入合计），Day 11 真心话环节不限次数。


## 三、顶部 Header 功能按钮

游戏顶部 Header 区域集中了所有功能入口和状态信息：

### 好感度区域（左侧）
- **成员头像**：3 位成员的小头像 + 当前好感度数值/描述
- **❤️ 好感度提示**：点击打开好感度详细面板（`showAffectionPanel`）
- **⏳ 倒计时**：Day ≥ 10 时显示「距离最终选择还有 X 天」（红色脉冲动画）

### 功能按钮（右侧，从左到右）

| 图标 | 悬停提示 | 功能 |
|------|---------|------|
| ⚙️ | API设置 | 打开 API Key、模型提供商、模型名称设置弹窗 |
| ❓ | 规则速览 | 打开游戏规则帮助弹窗 |
| 📖 | 历史剧情回顾 | 查看之前所有天的剧情记录（完整回放） |
| 📋 | 查看X档案 | 查看前任 X 的秘密故事档案 |
| 📜 | 查看短信历史 | 查看所有发送过的心动短信记录（气泡聊天式时间轴） |
| 📝 | 心动笔记 | 查看好感度/秘密任务解锁的心动笔记（有笔记时才会显示） |
| 🎁 | 送礼记录 | 打开送礼面板，查看已有礼物或赠送新礼物 |
| 📥 | 导出剧情记录 | 将全部剧情记录导出为 .txt 文件 |
| 💾 | 导出存档 | 将游戏存档导出为 JSON 文件（文件名含日期） |
| 📂 | 导入存档 | 选择 JSON 存档文件导入，含安全校验和确认覆盖弹窗 |
| 📞 | 午夜电话记录 | Day 7 后查看午夜电话反馈记录（条件触发时才显示） |
| 🔄 | 重置游戏 | 重置所有游戏进度，保留 API 设置、主题偏好和打字机速度 |
| 🌙 / ☀️ | 切换主题 | 循环切换：深色 → 浅色 → 跟随系统，自动保存偏好 |

### 打字机速度调节

Header 右侧下拉框 `typewriterSpeedSelect`，5 档可选：

| 档位 | 行为 |
|------|------|
| 即时 | 跳过逐字动画，直接显示完整文本 |
| 慢 | 每字约 100ms |
| 中（默认） | 每字约 50ms |
| 快 | 每字约 20ms |
| 极快 | 每字约 10ms |


## 四、底部操作栏（Action Bar）

底部操作栏根据当前游戏状态动态显示不同按钮：

### 常规按钮

| 按钮 | 触发时机 | 功能 |
|------|---------|------|
| 🔄 重新生成本段 | 始终显示 | 重新调用 AI 生成当前时段的剧情 |
| ▶ 跳过进入下一时段 | 当前时段结束后 | 推进到下一时段 |
| ▶ 进入下一天 | 深夜时段剧情结束后 | 进入下一天（含记忆压缩和次日预告） |

### 深夜专属按钮

| 按钮 | 触发时机 | 功能 |
|------|---------|------|
| 📞 午夜电话亭 | Day 6 深夜且未触发 | 触发午夜匿名电话事件，可打给任意成员 |
| 📨 发送心动短信 | 深夜且未发送过短信 | 打开手机样式短信弹窗，选择收件人输入内容 |
| ✅ 确认进入下一天 | 短信已发送 + 深夜 | 执行记忆压缩，AI 生成下集预告，推进到下一天 |
| ✍️ 继续今天（N/2） | 短信已发送 + 深夜 + 有剩余次数 | 额外生成 2 段延伸剧情（最多续 2 次，次数用完后按钮消失） |


## 五、剧情区域操作

### 选项面板（Option Panel）

AI 生成的选项以按钮形式展示在剧情下方：
- **A/B/C 选项**：点击触发 AI 生成对应后续剧情
- **进入约会场景**：约会日专用特殊选项，选择后直接跳转到约会时段
- **真心话选项**（Day 11）：如实回答 / 拒绝并喝酒 / 观看其他成员回合
- **提问箱选项**（Day 7 傍晚）：如实回答 / 拒绝并喝酒（+2 杯）

### 自由输入区（Free Input）

底部输入框区域，三个按钮：

| 按钮 | 功能 |
|------|------|
| 💾 保存 | 保存当前输入内容（不提交给 AI） |
| ❌ 清空 | 清空输入框和已保存内容 |
| ✍️ 生成剧情 | 提交输入给 AI，生成自定义剧情回应 |

### 通知条（横跨剧情区的特殊事件条）

| 通知条 | 触发条件 | 操作按钮 |
|--------|---------|---------|
| 秘密任务 | 制作组给女主指派秘密任务时 | ✅ 我已完成任务（需确认弹窗确认） |
| 嫉妒任务 | 某位成员吃醋时 | 仅展示文字，无操作按钮 |
| 前任来电/来信 | Day 5-9 傍晚/深夜，15% 概率 | A 假装没看见 / B 安慰他 / C 追问详情 |

| 弹窗 | 入口 | 说明 |

| 心动短信 | 深夜「📨 发送心动短信」 | 手机气泡 UI，选择收件人 + 输入内容发送 |

| X 档案 | Header 📋 | 查看前任 X 的背景故事和各成员视角的 X 故事 |

| 送礼面板 | Header 🎁 | 选择礼物和赠送对象，可改造已有礼物 |
| 回礼弹窗 | 送礼后次日自动弹出 | 成员收到礼物后的回礼展示，好感 +2 |
| 心动笔记 | Header 📝 | 好感度 40/60/80 和秘密任务解锁的笔记合集 |
| 历史剧情回顾 | Header 📖 | 完整回放所有天的剧情文本 |
| 规则速览 | Header ❓ | 游戏规则说明，按当前进度高亮相关规则 |
| API 设置 | Header ⚙️ | 配置 API Key、提供商、模型名称 |
| 约会骰子 | 约会日前自动弹出 | 随机决定约会配对对象 |
| Day10 自由约会 | Day 10 触发 | 自由选择约会对象 |
| 午夜电话亭 | Day 6 深夜 📞 | 匿名打电话给任意成员，好感变动 |
| 醉酒选人 | Day 11 深夜喝酒 ≥ 2 杯触发 | 选择被真心话惩罚的对象 |
| 真心话回答 | 真心话环节自动弹出 | 输入回答或选择拒绝喝酒 |

### 约会骰子机制
约会日（Day 4/6/8/9）进入上午剧情后，自动弹出约会骰子弹窗：
- 3 位成员随机配对，匹配到不同对象触发不同剧情
- Day 9 是特殊 X 约会日，强制与前任 X 单独约会

### 回礼机制
- 送礼后次日自动弹出回礼弹窗展示成员回礼
- 回礼好感度 +2


## 七、特殊事件系统

| 事件 | 触发条件 | 说明 |
|------|---------|------|
| 前任来电/来信（exMessage） | Day 5-9 傍晚/深夜，15% 概率 | 前任试探联系，三选一回应影响好感 |
| 午夜匿名电话亭（midnightCall） | Day 6 深夜 | 匿名打给任意成员，目标 +5，其他人 -2 |
| 匿名提问箱（questionBox） | Day 7 傍晚 | 随机 4 题，被抽中可选回答或喝酒 |
| 真心话惩罚版（truthPunishment） | Day 11 深夜，喝酒 ≥ 2 杯 | 公主抱/强制独处/反问三种惩罚 |
| X 幽灵事件（xGhostEvent） | Day 3-5，15% 概率 | 场外 X 的碎片痕迹（字条/来电/旧物） |
| 修罗场（rivalry） | ≥ 2 位成员好感 ≥ 60 时激活 | 成员暗中较劲或正面冲突 |
| 记忆闪回（flashback） | 好感度突破 80，20% 概率 | 注入往昔甜蜜回忆片段 |
| 秘密任务 | 每日随机触发 | 完成指定任务获得奖励 |
| 嫉妒任务（jealousyMission） | 特定条件触发 | 某成员因你和别人互动吃醋 |


## 八、关键系统速查

| 系统 | 说明 |
|------|------|
| 好感度 | 每位成员独立计算，5 档描述：💔(<0) → 💙(0-14) → 😐(15-39) → 💚(40-59) → ❤️(60-79) → ❤️🔥(80+) |
| 好感度飘字 | 好感变化时从成员头像旁飘出绿色(+N)/红色(-N)动画 |
| 全屏特效 | 💔 心碎粒子（好感大跌）、⚡ 白色闪屏（关键真相）、✨ 金色光环（好感达 80） |
| 喝酒计数 | Day 11 深夜统计分析，影响真心话惩罚触发 |
| 每日记忆快照 | 每天结束自动记录好感度快照，供结局折线图使用 |
| 下集预告 | 每天结束时 AI 生成悬念预告文字，全屏淡入 3.5 秒 |
| 成员立绘 | 好感度 5 档对应不同立绘（cold/calm/care/love/passion），加载失败 emoji 回退 |
| 倒计时仪式感 | Day ≥ 10 Header 显示红色脉冲倒计时 |


## 九、最终选择（Day 12）

最后一天你必须做出选择：
- **复合**：回到 X 身边
- **换乘**：选择新的成员

每位成员也会同时做出选择——双向奔赴才是圆满结局。
结局时展示好感度变化折线图和完整结局故事。


## 十、存档与数据

| 功能 | 操作方式 |
|------|---------|
| 自动存档 | 每次操作后自动保存到浏览器 localStorage |
| 存档导出 | 点击 Header 💾 按钮，下载 JSON 存档文件 |
| 存档导入 | 点击 Header 📂 按钮，选择 JSON 文件导入（含安全校验） |
| 重置游戏 | 点击 Header 🔄 按钮，保留 API 设置 / 主题 / 打字机速度 |
| 导出剧情记录 | 点击 Header 📥 按钮，导出全部剧情为 .txt 文件 |
| 结局图鉴 | 结局画面点击 📚 查看所有已解锁结局 |
| 导出结局 | 结局画面点击 📥 将结局记录导出为 .txt 文件 |

### 深色模式

Header 🌙 按钮循环切换：深色 → 浅色 → 跟随系统
偏好自动保存到浏览器，下次打开游戏自动恢复。


## 十一、注意事项

- 首次进入 Day 4/6/8/10 等特殊节点时，AI 生成可能需要等待 10-30 秒
- 短信每晚只能发 1 条，Day 1-7 不能发给 X
- 每个时段上限 3 次操作（选项 + 自由输入合计），Day 11 不限
- 如果 AI 生成失败，点击「🔄 重新生成本段」重试
- 建议使用 Chrome / Edge 浏览器，移动端需保持屏幕常亮
- 所有 AI 生成文本已做安全转义处理
