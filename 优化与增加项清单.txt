# 换乘恋爱 × SEVENTEEN — 游戏优化与增加项清单
# 生成日期: 2026-06-20
# 说明: 基于 SEVENTEEN.html (v20) 与 SEVENTEEN.txt (规则书 v3.0) 的完整评估

================================================================================
一、视听体验增强（非代码层 / 需素材配合）
================================================================================

1. 背景音乐（BGM）与音效系统
   - 分时段/分场景播放不同氛围音乐（清晨、深夜、约会、真心话）
   - 音效：骰子滚动声、短信到达提示音、心跳加速提示、采访间转场音、好感度提升提示音
   - 成员专属短信提示音（根据发送对象不同播放不同音效）

2. 视觉素材层
   - 13 位成员的头像/立绘（随好感度阶段变化表情：冷淡→微笑→脸红）
   - 场景背景图（客厅、厨房、阳台、采访间、约会地点）
   - CG 事件插图收集系统（关键剧情节点自动生成画面提示词并归档至画廊）
   - 小屋季节/天气动态背景（配合随机事件系统）

3. UI/UX 动画
   - 剧情文本打字机效果（可调节速度/可关闭）
   - 选项浮现动画、采访间切换转场效果
   - 好感度变化飘字动画（+2 / -1 从角色头像旁飘出）
   - 短信界面拟真手机震动/发送动画

================================================================================
二、核心玩法扩展（可代码实现）
================================================================================

4. 多周目与继承系统
   - 通关后开启「二周目」：继承部分 X 档案解锁度、获得「回忆碎片」货币
   - 多结局收集图鉴（复合/换乘/独自离开 × 3 位成员 = 至少 9 种结局分支）
   - 成就徽章系统（如「全员好感度 80+」「一次都没给 X 发短信」「真心话全坦白」）

5. 小游戏与轻互动
   - 厨房协作家务（简易节奏/选择小游戏，影响当晚好感度）
   - 拍照环节：玩家选择构图/成员站位，生成专属 CG 描述
   - 礼物 DIY：不只是选择模板，可输入自定义文字/挑选颜色，影响成员后续反应

6. 深度剧情机制
   - 秘密任务系统：制作组偶尔给女主秘密任务（如「今天让某位成员笑出来」），完成有额外好感或隐藏剧情
   - 连锁随机事件：当前随机事件孤立，可增加事件因果链（如 Day 2 下雨→Day 3 有人感冒→触发照顾剧情）
   - if 线/平行世界：通关后解锁「如果当初选了另一位」的短篇后日谈

7. 嫉妒（Jealousy）与成员间冲突
   - 当两位成员好感度都 ≥60 时，触发隐性竞争事件（如同时邀约、暗地较劲）
   - 可爆发轻微冲突剧情，玩家选择站队或调和，影响两人好感走向

================================================================================
三、系统与数据功能（可代码实现）
================================================================================

8. 存档系统升级
   - 多存档槽位（当前仅单存档 localStorage）
   - 存档导出/导入（生成 JSON 文件或 Base64 字符串，便于分享/换设备）
   - 自动云端备份（可选，对接 WebDAV/网盘 API）

9. 数据统计与可视化
   - 个人游玩数据中心：总时长、总字数阅读、选择倾向饼图
   - 单周目好感度变化折线图（Day 1→Day 12 每位成员的曲线）
   - 短信统计雷达图（发给谁最多、谁深夜回复最快）
   - 情感网络图：最终日显示四人关系网强度

10. 剧情回放与画廊
    - 纯净模式回放：仅正文，去除标记，像读小说一样回顾
    - 短信历史增强为聊天式时间轴（当前是列表，可改为聊天气泡式）
    - 经典台词收藏夹（玩家可手动收藏任意句子，跨周目保留）
    - CG/插图画廊 + 生成提示词复用功能

11. 搜索与定位
    - 历史剧情关键词搜索（支持搜成员名、事件、对话内容）
    - 快速跳转至某 Day / 某时段 / 某成员相关剧情

================================================================================
四、角色与叙事深度（可代码实现）
================================================================================

12. 角色档案深化
    - 成员专属「心动笔记」：随着好感提升，逐步解锁该成员的私密设定（怕黑、喜欢的歌、童年故事）
    - X 档案 3D 化：记忆物品可点击查看大图 + AI 生成的物品背景故事
    - 场外 X 的「背影」：当前场外 X 完全不出场，可增加声音/信件/照片等碎片化出现

13. 女主自定义扩展
    - 增加「声线」设定（影响采访间文本语气描述，如清冷/软糯/平静）
    - 自定义服装/穿搭（每天可选，影响成员反应与观察员评论）
    - 更丰富的外貌特征选项（发型、瞳色、身高），在剧情中更高频自然地提及

14. 观察员与综艺感再升级
    - 弹幕系统：观察员发言时，模拟观众实时弹幕飘过（增加沉浸感）
    - 下集预告生成：每天结束时 AI 生成次日预告文案（类似韩剧「下集更精彩」）
    - 特邀嘉宾轮换可视化：显示本期嘉宾头像与「insider 爆料」合集页面

五、技术与性能优化（可代码实现）
================================================================================

15. PWA 与离线能力
    - 注册 Service Worker，支持离线查看历史剧情与已缓存内容
    - 添加到主屏幕，全屏运行更像原生 App
    - 本地缓存 AI 常用回复模板，弱网环境下可基础游玩

16. 性能与长文本优化
    - 历史剧情虚拟滚动（解决 12 天累积文本过多时的 DOM 渲染卡顿）
    - 文本分段懒加载（非当前时段内容按需加载）
    - 图片/背景懒加载（如有大量素材时）

17. AI 层优化
    - 支持多模型切换（DeepSeek / Claude / GPT / 本地模型 Ollama）
    - Prompt 压缩与缓存：相同上下文的重复调用结果本地缓存，节省 Token
    - AI 一致性校验器：自动检测成员人设偏离（如全圆佑突然话多、崔胜澈不照顾人）并标红提醒玩家

六、社交与内容生态（部分可代码实现，部分需后端）

18. 分享与传播

19. 可扩展性（MOD 框架）

    - 剧本工坊接口：高级玩家可编写固定事件插入主线的 JSON 格式剧本

七、辅助与无障碍（可代码实现）

20. 辅助功能
    - 文本朗读（TTS）模式，支持夜间听剧情（调用浏览器原生 speechSynthesis）

    - 玩法提示浮层（首次进入短信/约会/真心话/醉酒时弹出）

实施优先级建议
================================================================================

【第一批：高价值 + 低复杂度】（约 1-2 天工作量）
- 存档导出/导入
- 短信历史气泡化
- 深色模式
- 经典台词收藏夹
- 规则书检索
- 好感度飘字动画
- 新手引导

【第二批：核心体验增强】（约 3-5 天工作量）
- 多周目与继承系统
- 数据统计与折线图/饼图
- 剧情搜索与纯净回放
- 嫉妒与冲突系统
- 秘密任务系统
- 心动笔记解锁

【第三批：沉浸感深化】（约 5-7 天工作量，部分需素材）
- PWA 离线能力
- 成员档案深化（X 档案物品故事页）
- 自定义穿搭与声线
- 弹幕系统与下集预告
- 小游戏（厨房协作、拍照站位）
- 存档多槽位

【第四批：生态与扩展】（长期）
- MOD 框架与剧本工坊
- 赛季制活动接口
- 云端备份
- 全素材配音/立绘/BGM 整合

================================================================================
备注
================================================================================

- 当前游戏为单文件 HTML + 纯前端 JavaScript 架构，无后端服务器。
- 所有「可代码实现」的增项均在该架构内可行，不引入额外依赖。
- 涉及音频、图片、视频等二进制素材的功能，代码层可预留播放/展示逻辑，但素材文件需自行准备。
- AI 多模型切换需用户自行配置各平台 API Key 与 Endpoint，代码仅提供切换接口。
