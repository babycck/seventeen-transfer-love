## 用户需求

修复娱乐圈模拟器（entSim）中「全局角色知晓私人消息」的天眼问题：女主通过手机私下发送的消息（泡泡/与男主的私聊），不应被其他角色在剧情中主动提及或"知道"，除非女主当面告知。

## 核心功能

- 在 AI 生成剧情时，禁止任何角色表现出对女主私人通信内容（泡泡消息、私聊记录、短信）的知情
- 在每日记忆压缩时，过滤掉涉及私密通信的关键词和事件，防止通过记忆系统永久泄漏
- 保留玩家在主剧情中主动当面告知某角色的能力（当面说出口的信息不属于私密通信）

## 技术方案

### 泄漏路径回顾

| 路径 | 机制 | 严重程度 |
| --- | --- | --- |
| 自由输入回传 | 玩家在主剧情自由输入中提及私聊内容 → 文本进入主 prompt（prompts.js:138）→ 所有角色"知道" | 高 |
| 记忆压缩传染 | 含私聊引用的 narrative 写入 `_entSimNarrativeBuffer`（engine.js:88）→ 换天压缩后注入后续 prompt（memory.js:13, prompts.js:228） | 高 |
| AI 幻觉 | system prompt 无规则禁止角色知晓私密通信，AI 自行编造 | 中 |


### 修复策略

**不做代码级过滤（改动太大、误伤风险高），而是通过 prompt 规则引导 AI 行为：**

1. **System Prompt 追加「私密通信隔离」规则**（prompts.js 第 92 行之后）

- 明确列出私密通信类型：泡泡（粉丝付费平台发的消息）、手机私聊、短信
- 禁止其他角色在剧情中主动引用或"知道"这些内容
- 例外：女主当面告知的可用「你之前跟我说过...」表述
- 与现有「禁止上帝视角」规则形成递进——内心想法 + 私密通信双重隔离

2. **记忆压缩 prompt 追加过滤指示**（memory.js 第 25-26 行）

- 在压缩指令中提醒 AI：不要将与私密通信（手机聊天/泡泡/短信）相关的内容作为关键事件或关键词提取
- 防止私密话题通过压缩进入记忆快照，从而注入到未来所有 prompt

### 关键设计决策

- **不做记忆缓冲过滤**：在 `_entSimNarrativeBuffer` 或 `compressEntSimMemory` 中做关键词过滤（如过滤"泡泡""私聊"）会误伤正常剧情（如角色当面讨论泡泡功能），且正则匹配不可靠。改为 prompt 引导更精准。
- **不隔离自由输入**：自由输入是玩家主动输入，如果玩家在主剧情中主动提及私聊内容，则视为女主当面告知，不应拦截。规则仅禁止 AI 自行编造角色知晓私密通信。
- **复用现有规则格式**：与第 92 行「禁止上帝视角」保持相同的格式风格（【XX·强制】标题 + 详细说明 + 正面/反面示例）。
