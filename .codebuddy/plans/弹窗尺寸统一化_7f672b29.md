## 产品概述

统一所有弹窗的尺寸，解决当前各弹窗宽度从 360px 到 580px 不等导致的"一下大一下小"视觉不一致问题。

## Core Features

- 统一所有弹窗（含确认弹窗和短信弹窗）为 500px 宽度、88vh 最大高度
- 清理各弹窗文件中的内联尺寸覆盖，统一回退到 CSS 默认样式
- 弹窗内容区采用 flex column 布局，内部滚动更自然

## Tech Stack

- 样式：CSS 变量化（`src/style.css`），无新依赖
- 代码约定：使用 `var`，字符串拼接用 `+`

## Implementation Approach

### 策略

修改 `.modal-content` 的默认 CSS 样式为统一目标值，然后清理所有常规弹窗文件中的内联 `width`/`max-width`/`max-height` 覆盖，让它们回退到默认值。改动最小且未来新弹窗自动统一。

### 关键决策

| 决策 | 理由 |
| --- | --- |
| 目标尺寸 500px | 各弹窗宽度的中间值（当前 360-580px），兼顾内容密度和移动端兼容 |
| max-height 统一 88vh | 折中原来的 85vh 和 90vh |
| 统一加 `display:flex;flex-direction:column` | Tab 弹窗的 Tab 内容区滚动更自然，非 Tab 弹窗也无副作用 |
| confirm-modal 500px | 用户要求全部统一，不再保留 400px 特殊尺寸 |
| sms-modal 500px | 用户要求全部统一，手机 UI 内部容器仍可保持手机样式，外层弹窗统一 |
| `overflow-y:auto` 从 `.modal-content` 移到内部内容区 | flex column 布局下，让内部滚动而非整个弹窗滚动 |


### 性能考量

- 纯 CSS/内联样式清理，无 JS 逻辑变更，无性能影响
- 清理内联样式减少 DOM 属性数量

## Implementation Notes

- **不修改 JS 逻辑**：只清理内联 style 中的 `width`/`max-width`/`max-height`/`display`/`flex-direction` 属性，保留其他内联样式（如 `text-align:center`）
- **confirm-modal 和 sms-modal 也纳入统一**：用户明确要求全部统一
- **sms-modal 特殊处理**：外层 modal-content 统一 500px，内部手机 UI 容器（phoneStyle）保持原样
- **gift-panel.js 有 3 处** `modal-content`（送礼面板/回礼弹窗/改造礼物），需逐一处理
- **dating-dice.js** 有 `text-align:center` 内联样式，只清理尺寸相关属性，保留 text-align
- **深色模式兼容**：统一尺寸不涉及颜色变量，深色模式自动兼容

## Architecture Design

不涉及架构变更，仅 CSS 样式统一。
