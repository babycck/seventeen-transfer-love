增大 API 超时时间至 90 秒，解决 DeepSeek JSON 模式 + 长 prompt 在高负载时 60 秒不够用导致的 AbortError。

## Tech Stack

- Current: JavaScript, Vite 5.4, DeepSeek API
- No new dependencies needed

## Implementation

### 改动点

`src/api.js:417` — `var timeoutId = setTimeout(function() { controller.abort(); }, 60000);`
→ `var timeoutId = setTimeout(function() { controller.abort(); }, 90000);`

`src/api.js:415` — 更新注释 `60s` → `90s`

### 原因

- 每次重试用全新 90s 超时，首次和末次都获得 90 秒窗口
- maxAttempts=2，高峰期即使第 1 次超时，第 2 次也有 90 秒窗口
- 90s 是 DeepSeek JSON 模式常见最大延迟（含排队）的安全上限，避免用户等待过久
