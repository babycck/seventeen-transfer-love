## 用户需求

用户在测试 💗只为你心动（1v1）模式时发现：女主私密体质为「多选」设置，自己并未勾选「敏感带在耳后」，但生成的剧情里却出现了"耳后敏感带"的描写。核心诉求——**女主拥有什么私密体质，必须以用户勾选为准；没选的，绝不能出现在剧情里（选了什么就是什么）**。

## 产品概述

修正私密体质的注入与校验逻辑：把"特征固定位置说明"从无条件写死改为仅针对女主实际拥有的特征；并新增校验兜底，确保 AI 即便编造了未选体质也会被纠正重写。

## 核心功能

- prompt 中"注意"类说明仅对女主**实际拥有**的特征生效（外貌入 `appearance`、私密体质入 `privateTraits`）；未选的「敏感带在耳后」等绝不进入 AI 设定。
- 新增校验兜底：生成剧情文本包含某私密体质名称但该体质不在 `privateTraits` 中时，判定违规并回写 correction 强制 AI 重写。
- 已选私密体质、外貌特征、模板/随机人设逻辑不受影响；换乘模式与 1v1 模式同步修复。

## 技术栈

Vanilla JS (ES Modules) + Vite，复用现有 prompt 构建与校验器，不引入新依赖、不新增状态字段。

## 实现方案

### 根因

`src/prompts.js` 两处把若干特征（含私密体质项「敏感带在耳后」）当成女主**固有特征**无条件写死注入：

- 行 138（换乘经典模式 `buildSystemPrompt`）
- 行 981（1v1 模式 `buildOneHeartSystemPrompt`）

AI 被强制暗示女主"本就有敏感带在耳后"，即便 `hp.privateTraits` 不含该项，也会在亲密/触碰场景写出耳后描写。其余注入点（`prompts.js:136/448/977`、`formatters.js:44`、`x-archive.js:27`、帮助弹窗）均只取用户所选，本身正确。

### 关键决策

1. **prompt 层修复（主因）**：新增 `buildFeaturePosNote(hp)`，仅当女主实际拥有该特征时，才输出其"固定位置"说明。三项均无则整句省略。用其替换 138/981 的硬编码字符串。
2. **validator 层兜底（加固）**：新增 `checkPrivateTraitViolation(content)`，遍历 `PRIVATE_TRAITS`，若名称出现在正文但不在 `GS.heroineProfile.privateTraits` 中，则判定违规（warning 级），引擎层会带 correction 重试。覆盖面广、误报率低（这些名称均为特异短语，正常叙述极少自然出现）。
3. 保持"最小改动"：helper 放在 `prompts.js` 内复用 `hp` 对象，无需新增 import；validator 仅需补充 `PRIVATE_TRAITS` 导入与一次函数调用。

### 性能与可靠性

- `buildFeaturePosNote` 为纯同步字符串拼接，仅 3 次 `indexOf`，开销可忽略。
- validator 新增检查为 O(特征数 × 文本长度) 的 `indexOf`，约 23 次，对每次生成无感知影响。
- 防回归：`hp.privateTraits` 为空时 helper 返回 `''`、validator 全量检查但仅命中未选项；旧存档 `privateTraits` 缺失已在 `state.js:400` 兜底为 `[]`，validator 内再 `|| []` 双保险。
- 不影响范围：外貌特征、已选私密体质、模板/随机人设（`ui-renderer.js:780/805` 写入 `privateTraits` 后即算"已选"）、称呼修复（上一任务）等逻辑互不干扰。

## 实现备注

- 遵循 `var` 风格与 `+` 字符串拼接，不引入模板字符串。
- validator 校验按现有模式返回 `{type, message}` 并由 `addSeverity(..., 'warning')` 包裹，与其他内容校验一致。

```js
// src/prompts.js —— 仅针对女主实际拥有的特征输出固定位置说明
function buildFeaturePosNote(hp) {
  var notes = [];
  if (hp.appearance.indexOf('泪痣') >= 0 || hp.appearance.indexOf('狐狸眼泪痣') >= 0) {
    notes.push('「泪痣」「狐狸眼泪痣」是眼角的痣');
  }
  if (hp.appearance.indexOf('锁骨精灵骨') >= 0) {
    notes.push('「锁骨精灵骨」是锁骨线条');
  }
  if (hp.privateTraits.indexOf('敏感带在耳后') >= 0) {
    notes.push('「敏感带在耳后」是耳后区域');
  }
  if (notes.length === 0) return '';
  return '- 注意：' + notes.join('，') + '，每个特征在各自固定位置，不可混淆。\n';
}

// src/validator.js —— 未选私密体质不得出现在剧情
function checkPrivateTraitViolation(content) {
  var corrections = [];
  var selected = (GS.heroineProfile && GS.heroineProfile.privateTraits) || [];
  for (var i = 0; i < PRIVATE_TRAITS.length; i++) {
    var t = PRIVATE_TRAITS[i];
    if (selected.indexOf(t) >= 0) continue;
    if (content.indexOf(t) >= 0) {
      corrections.push({
        type: 'privateTrait',
        message: '剧情中出现了未选择的私密体质「' + t + '」，女主并未设定该体质，请删除或改写为与已选体质（' + (selected.length ? selected.join('、') : '无') + '）相关的描写。'
      });
    }
  }
  return corrections;
}
```
