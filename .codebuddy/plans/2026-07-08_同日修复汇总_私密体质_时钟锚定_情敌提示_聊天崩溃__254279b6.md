## 用户需求

测试 💗只为你心动（1v1）模式时发现 4 类问题，要求全部修复，做到"选了什么就是什么、时段与用餐自洽、好感提示不串、聊天不崩溃"。

## 产品概述

对 1v1 模式的 prompt 注入、内容校验、好感结算、存档写入四处进行修正与兜底，保证 AI 生成内容符合女主实际设定与时钟锚定，且前端渲染不崩溃。

## 核心功能

- 私密体质"选了才是"：未勾选的私密体质（如敏感带在耳后）绝不出现在剧情；prompt 仅对女主实际拥有特征注入位置说明，validator 兜底拦截编造。
- 1v1 时钟/用餐锚定：保持每天 4 段（每段 +4 小时）不变，修正时段边界使午饭归位；prompt 注入"用餐锚定"明确该不该写吃饭；validator 禁止非午饭时段写午饭。
- 情敌事件好感提示错乱（显示层 + 逻辑层双修）：情敌倾向提示改到底部并加【情敌倾向】前缀，与顶部男主好感飘字区分；移除"情敌匹配即吞掉男主好感"逻辑，男主好感始终结算，情敌仅经显式 rivalAffDelta 更新。
- 聊天记录崩溃修复：主动消息写入取字符串字段，escHtml 增加字符串化兜底，chat-modal 渲染前 typeof 归一，打开聊天弹窗不再崩溃。

## 技术栈

Vanilla JS（ES Modules）+ Vite，复用现有 prompt 构建、校验器、好感度与渲染模块；不引入新依赖、不新增状态字段。

## 实现方案

### 1. 私密体质选了才是（主因 + 兜底）

- `src/prompts.js`：新增 `buildFeaturePosNote(hp)`，仅当 `hp.appearance` / `hp.privateTraits` 实际包含该特征时才输出其"固定位置"说明；用其替换换乘模式（~138）与 1v1 模式（~981）两处硬编码"注意：泪痣…敏感带在耳后…"串。三特征均无则返回空串。
- `src/validator.js`：导入 `PRIVATE_TRAITS`；新增 `checkPrivateTraitViolation(content)`，遍历 `PRIVATE_TRAITS`，正文出现某体质名但未在 `GS.heroineProfile.privateTraits` 中时回写 correction（warning 级），引擎带 correction 重试。换乘 / 1v1 同步生效。

### 2. 1v1 时钟 / 用餐锚定（保持 4 小时跨度）

- `src/utils.js`：调整 `ONE_HEART_TIME_PERIODS` 边界为 `上午8-12 / 中午12-13 / 下午13-18 / 傍晚18-21 / 深夜21-24`，使 +4 时钟序列正确命中 `8=上午 / 12=中午 / 16=下午 / 20=傍晚`，午饭天然归位；`clock=24` 由引擎跨天回滚到 8，不会落到错误 label。
- `src/prompts.js`：新增 `getOneHeartMealHint(clock)`，按 `oneHeartDayClock` 给出"现在该不该写吃饭"指引，显式禁止非午饭时段写午饭；在 1v1 user message `[场景状态]` 注入后追加一行 `[用餐锚定]`。
- `src/validator.js`：新增 `checkTimeMealMismatch(content)`（仅 `gameMode==='oneHeart'` 生效），正文出现"午饭/午餐/午休"但时钟不在 `11-13` 时回写 correction 强制重写。

### 3. 情敌事件好感提示错乱（显示层 A + 逻辑层 B）

- `src/utils.js`：`showToast(message, pos)` 增加 `pos` 参数，`pos==='bottom'` 时改为 `bottom:20px`（屏幕底部居中）。
- `src/affection.js`：`updateRivalTendency` 内 Toast 改为 `showToast('【情敌倾向】' + _label + _sign + delta, 'bottom')`，与顶部 Header 男主好感飘字在位置 + 文案双重区分。
- `src/game-engine.js`：`applyOneHeartOptionAffection` 移除"情敌匹配即整段 return 吞掉男主好感"逻辑；男主 `affDelta` 始终经 `updateAffection` 结算，仅当选项**显式**带 `rivalAffDelta`（且未转正）才 `updateRivalTendency`。并在 1v1 prompt 注入"情敌选项规则"引导 AI 用 `rivalAffDelta` 表达情敌取向。

### 4. 聊天记录 content 为对象导致 escHtml 崩溃

- `src/game-engine.js`：1v1 主动消息路径 `GS.chatHistory.push({role:'ai', content:_msg})` 改为取 `_msg.text`（支持字符串/对象兜底），空则跳过；保持 50 条上限与 `saveGame()`。
- `src/utils.js`：`escHtml` 增加字符串化兜底——`undefined/null` 返回空串，非字符串且真值 `return String(s)`，杜绝任何对象/数字漏网导致整页崩溃。
- `src/modals/chat-modal.js`：渲染循环前对 `c.content` 做 `typeof` 归一（非字符串则取 `.text` 或 `String` / 跳过），双保险。

## 实现备注

- 遵循项目 `var` 风格与 `+` 拼接，禁止模板字符串；不引入新依赖。
- validator 校验沿用现有模式：返回 `{type, message}` 并由 `addSeverity(..., 'warning')` 包裹，与其他内容校验一致。
- `hp.privateTraits` 缺失时 `state.js:400` 已兜底为 `[]`，validator 内再 `|| []` 双保险，防旧存档。
- 性能：上述 helper 均为同步字符串拼接 / `indexOf` 校验（O(特征数×文本长度)），对每次生成无感知影响。

// src/prompts.js —— 仅对女主实际拥有特征输出位置说明
function buildFeaturePosNote(hp) {
  var notes = [];
  if (hp.appearance.indexOf('泪痣') >= 0 || hp.appearance.indexOf('狐狸眼泪痣') >= 0) notes.push('「泪痣」「狐狸眼泪痣」是眼角的痣');
  if (hp.appearance.indexOf('锁骨精灵骨') >= 0) notes.push('「锁骨精灵骨」是锁骨线条');
  if (hp.privateTraits.indexOf('敏感带在耳后') >= 0) notes.push('「敏感带在耳后」是耳后区域');
  if (notes.length === 0) return '';
  return '- 注意：' + notes.join('，') + '，每个特征在各自固定位置，不可混淆。\n';
}

// src/validator.js —— 未选私密体质不得出现 + 非午饭时段不得写午饭
function checkPrivateTraitViolation(content) {
  var corrections = [];
  var selected = (GS.heroineProfile && GS.heroineProfile.privateTraits) || [];
  for (var i = 0; i < PRIVATE_TRAITS.length; i++) {
    var t = PRIVATE_TRAITS[i];
    if (selected.indexOf(t) >= 0) continue;
    if (content.indexOf(t) >= 0) corrections.push({ type: 'privateTrait', message: '剧情出现未选择的私密体质「' + t + '」，请删除或改写为与已选体质相关的描写。' });
  }
  return corrections;
}
function checkTimeMealMismatch(content) {
  var corrections = [];
  if (GS.gameMode !== 'oneHeart') return corrections;
  var clock = GS.oneHeartDayClock || 8;
  if (clock >= 11 && clock < 13) return corrections;
  var lunchKw = ['午饭', '午餐', '午休', '吃午饭', '吃午餐', '一起吃午饭', '一起吃午餐'];
  for (var i = 0; i < lunchKw.length; i++) {
    if (content.indexOf(lunchKw[i]) >= 0) { corrections.push({ type: 'timeMeal', message: '当前时钟 ' + clock + ' 时非午饭时间，却出现"' + lunchKw[i] + '"，请改为符合时段场景。' }); break; }
  }
  return corrections;
}
