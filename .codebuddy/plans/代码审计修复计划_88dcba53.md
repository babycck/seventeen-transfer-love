## 技术方案

### 修改清单（6 项，按依赖顺序排列）

**1. parser.js:318-319 — 修复 else if 调用了 showToast**

```
- showToast('✅ 秘密任务完成！' + ...);
+ alert('✅ 秘密任务完成！' + ...);
```

**2. modals/dating-dice.js:63-65 — 成员 name 过 escHtml**

```javascript
// 在文件顶部已 import escHtml，直接使用
protestHtml = ... escHtml(others[1].name) ...
```

确认 `dating-dice.js` 已 import `escHtml`（与 core.js 相同路径），直接使用。

**3. store.js:176-178 — 修 action creator 移除 payload 包裹**

```javascript
// 从 payload 包裹改为与 reducer 一致的顶层属性
pushConsequence: function(rawText, parsed, choiceText) {
    return { type: 'PUSH_CONSEQUENCE', rawText: rawText, parsed: parsed, choiceText: choiceText };
},
```

**4. store.js:59-61 — 删除 SET_FLAG case 及 FLAG_WHITELIST**
移除整个 `case 'SET_FLAG':` 块和文件顶部的 `FLAG_WHITELIST` 变量定义，因为从未使用。需确认 `FLAG_WHITELIST` 在 store.js 中确实无其他引用。

**5. game-engine.js:267-270 — 删除 extractSmsDrafts 废弃函数**
函数注释写"改造，废弃"，且无调用方（需 grep 确认），删除整个函数。

**6. game-engine.js:981-983 — 简化 settlePendingAffChanges 转发函数**

```javascript

// 在顶部引入时已别名：import { settlePendingAffChanges as skeletonSettleAff }
```
