## 问题背景

用户反馈：点击日程区域中新增的「队友互动」按钮，未弹出选择面板，而是直接进入AI剧情生成——与主档/相关/情敌/哥哥按钮行为一致，说明 `showTeammateSelectPanel()` 未被成功调用或调用后静默退出。

## 根因分析（3个可能）

1. **旧存档 heroineGroup 为空**：`src/state.js:454` migration 对缺失/非数组的 `heroineGroup` 仅兜底为 `[]`，不重建。`showTeammateSelectPanel` 发现 `list.length === 0` → toast 提示后 return，看起来像什么都没变。
2. **buildHeroineGirlGroup 未导出**：该函数在 `src/ent-sim/state.js:128` 以普通 `function` 声明，未 export，`ui.js` import 列表中也不含它。即使 ui.js 想重建队友列表也调不到。
3. **无调试日志**：无法区分是按钮事件未绑定、`onAgendaClick` 未走到 `teammate` 分支、还是进入 `showTeammateSelectPanel` 后因空数组退出。

## 修复目标

- 导出 `buildHeroineGirlGroup`，使 `ui.js` 可在 `heroineGroup` 为空时自愈重建
- 在 `showTeammateSelectPanel` 中加入空值自愈逻辑（尝试调用重建函数）
- 在 `onAgendaClick` / `showTeammateSelectPanel` 中加入 console.log 追踪链路
- 增强 migration：旧存档 `heroineGroup` 为空时重建而非仅兜底 `[]`

## 修改范围

仅涉及 3 个文件，最小改动：

| 文件 | 改动 | 目的 |
| --- | --- | --- |
| `src/ent-sim/state.js` | `buildHeroineGirlGroup` 前加 `export` | 允许外部调用 |
| `src/ent-sim/ui.js` | import 追加 `buildHeroineGirlGroup`；`onAgendaClick` 加日志；`showTeammateSelectPanel` 加空值自愈 + 日志 | 调试追踪 + 兜底修复 |
| `src/state.js` | migration 中 `E.heroineGroup = []` 改为 `E.heroineGroup = buildHeroineGirlGroup()`（需先 import） | 旧存档自动重建队友 |


## 实现细节

### 1. 导出 buildHeroineGirlGroup

`src/ent-sim/state.js` 第 128 行：`function buildHeroineGirlGroup()` → `export function buildHeroineGirlGroup()`。

### 2. ui.js 改动（3 处）

- **import 行**：追加 `buildHeroineGirlGroup` 到 `from './state.js'` 导入。
- **onAgendaClick**（约第 500 行）：第一行加 `console.log('[agenda-click] kind:', kind);`，分支进入时加 `console.log('[agenda-click] teammate branch hit');`。
- **showTeammateSelectPanel**（约第 815 行）：

```javascript
function showTeammateSelectPanel() {
console.log('[teammate-panel] called');
var E = GS.entSim;
var list = E.heroineGroup || [];
// 自愈：旧存档为空时重建
if (!list.length) {
console.log('[teammate-panel] heroineGroup empty, rebuilding...');
E.heroineGroup = buildHeroineGirlGroup();
list = E.heroineGroup;
saveGame();
}
if (!list.length) { showToast('暂时没有可互动的队友'); return; }
console.log('[teammate-panel] showing panel with', list.length, 'teammates');
// ... 后续不变
}
```

### 3. state.js migration 增强

`src/state.js` 需在文件顶部 import `buildHeroineGirlGroup`（路径 `./ent-sim/state.js`），然后将 line 454 的：

```
if (!Array.isArray(E.heroineGroup)) E.heroineGroup = [];
```

改为：

```
if (!Array.isArray(E.heroineGroup) || E.heroineGroup.length === 0) E.heroineGroup = buildHeroineGirlGroup();
```

## 无性能影响

- `console.log` 属于调试代码，上线时可保留（生产环境 console 不影响逻辑）
- 自愈重建仅触发一次（空数组时），后续走正常路径
- 不影响换乘恋爱 / 1v1 模式（entSim 专属路径）
