## 用户需求

修复「女主在 SEVENTEEN 内部群聊中发言/看到消息」的不合理设定。女主不是 SEVENTEEN 成员，不应该在 SVT 的 13 人内部工作群中。当前 prompt 规则写的是「SEVENTEEN 工作群——13 人+你被哥哥拉进去的」，导致 AI 生成剧情时让女主在群里自由发消息、点赞、被 @。

## 核心功能

- 修改群聊体系规则：SEVENTEEN 工作群改为「13 人内部群，女主不在其中」
- 女主获知 SVT 群聊内容的唯一合法路径：哥哥主动展示、某位 SVT 成员当面告知、被拉入临时协作群
- 替换事件池中 2 条「女主在群里互动」的事件为其他场景
- 替换男主主动互动池中 1 条「在群里 @ 你」的事件为其他渠道

## 不改动

- data.js:657「哥哥在 SEVENTEEN 工作群里说谁帮我妹搬下器材」——哥哥在群里发言完全合理，不涉及女主读群消息
- UI / engine / state 字段均不涉及

### prompts.js — 群聊规则重写

**旧规则（第 42-43 行）：**

```
(2) 「SEVENTEEN工作群」—— SEVENTEEN 13人+你被哥哥拉进去的，发行程/外卖/调侃/团内通知/经纪人指示。
```

**新规则设计：**

```
(2) 「SEVENTEEN 内部群」—— SEVENTEEN 13 人专属工作群（你不在其中）。发行程/外卖/调侃/团内通知/经纪人指示。这是他们的内部空间。
女主不在这个群里。你只能通过以下方式获知群内消息：
(a) 哥哥主动把手机屏幕亮给你看（"你看XX在群里说了什么"）
(b) 某位 SVT 成员当面口头转述（"刚才群里在讨论…"）
(c) 被哥哥临时拉入一个包含你和多位 SVT 成员的临时群（如帮忙搬器材、活动协作），任务完成后解散
在任何剧情中，禁止写「你在 SEVENTEEN 群里看到…」「你打开 SEVENTEEN 群」「你在群里回复/发消息/点赞」。禁止写 SEVENTEEN 成员在群里 @ 你（你不在群里无法被 @）。
```

关键设计点：

- 禁止女主「主动读取」群消息——只能被哥哥展示或被人告知
- 禁止女主「在群里发言」——她不在群里
- 保留「临时拉群」场景作为合法例外（对齐 data.js:657 的场景逻辑）
- 与现有「私密通信隔离」规则形成对称——SVT 的内部通信对女主也是隔离的

### 不改动的条目

data.js:657 保留原样：

```
{ vibe: '哥哥牵线', text: '哥哥在 SEVENTEEN 工作群里说"谁帮我妹搬下器材"，{{name}}秒回"我来！"…' }
```

这是哥哥在自己的群里发言，是合理的。女主不在群里，但这个事件描述的场景是：哥哥在群里说话 → 有人自告奋勇来帮忙 → 女主在现场见到那个人。不涉及女主读群消息。
